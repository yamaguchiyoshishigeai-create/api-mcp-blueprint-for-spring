APIM for Spring の目的

業務要件から API と MCP を同時に設計するための支援ツールです。

APIとMCPの違い

  • API: 人間・フロントエンド・他システム向け
  • MCP: AIエージェント向けの操作・参照入口

初期MVPで生成するもの

  • REST API候補
  • MCP tools/resources/prompts 候補
  • API/MCP対応表
  • セキュリティ・承認・監査ログ注意点
  • Markdown設計書とAI実装指示書

初期MVPで生成しないもの

  • 完全動作するMCPサーバー
  • 外部LLM API連携
  • DB永続化やマイグレーション
  • 認証・認可の本格実装
  • 本番デプロイ作業やRender公開作業

外部AIプロンプトブリッジ

外部AIプロンプトブリッジは、APIMが自由文からChatGPT等へ手動投入するためのプロンプトを生成する機能です。外部AI API連携ではなく、APIキー入力や保存、外部AIへの自動送信は行いません。

ユーザーが生成プロンプトを外部AIへ手動投入し、外部AIが返した APIM 取り込み用 JSON をAPIMへ貼り付けまたはアップロードします。JSONは検証後に既存入力フォーム状態へ反映され、ユーザー確認・修正を挟んでから最終成果物生成へ進みます。

削除、権限変更、外部送信、金銭・契約影響操作などの危険操作や書き込み操作は、承認・監査ログ観点で扱ってください。

Q-Scout for Spring との差別化

APIM for Spring は新規設計生成、Q-Scout for Spring は既存システム診断を対象とします。

AI実装指示書利用時の注意

出力は人間レビュー前提です。削除・権限変更・外部送信は承認フローを設計してください。
