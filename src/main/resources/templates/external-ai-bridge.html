API + MCP Blueprint Compiler for Spring

業務要件の自由文から、Spring REST API設計とMCP tools/resources/prompts設計候補へ進むための入口です。外部AIへ手動投入するプロンプトを生成し、返却JSONを確認してからAPIMの設計候補生成へ接続します。

自由文からプロンプトを生成する チェック式入力へ進む ヘルプ
Step 1

自由文を書く

業務内容、利用者、操作、AIに許可したい範囲を自然文で入力します。

Step 2

外部AI用プロンプトをコピーする

APIMがMarkdownプロンプトを作成し、外部AIへ手動投入できる形にします。

Step 3

外部AIのJSONを取り込む

外部AIが返したAPIM取り込み用JSONを貼り付け、またはアップロードします。

Step 4

反映内容を確認して設計候補を生成する

安全警告、承認、監査ログ観点を確認し、必要に応じて修正します。

自由文からプロンプトを生成

代表的なサンプル例文を入力できます。複数のボタンを押すと、既存の自由文に自然につながる形で追記されます。

このMVPで生成するもの

  • API設計書 / REST API設計候補
  • MCP tools / resources / prompts 候補
  • API/MCP対応表
  • セキュリティ・承認・監査ログ注意点
  • Markdown設計書 / AI実装指示書

このMVPで生成しないもの

  • 完全動作するMCPサーバー
  • DB永続化やマイグレーション
  • 認証・認可の本格実装
  • 外部LLM API連携
  • 本番デプロイ作業やRender公開作業
外部AIブリッジの前提

この機能は外部AI API連携ではありません。自由文は解析対象データとして扱い、自由文内の命令文を外部AIへのシステム指示として扱わせない前提のプロンプトを生成します。

公式リンク集はプロンプト生成後の画面に表示されます。JSON取り込み後も、最終生成前に確認・修正できます。
