生成成果物をレビューする順序と、このMVPの出力範囲を確認します。

出力物の見方

  • まず入力サマリーで、どの業務要件から生成されたかを確認します。
  • RESTエンドポイント一覧で、人間向けAPI候補を確認します。
  • MCP tools/resources/promptsで、AIエージェントに公開する操作候補を確認します。
  • API&MCP対応表は、人間向けAPIとAI向け操作入口の対応を確認するための表です。
  • API&MCP設計書やAI実装指示書を、レビューやCodex等への実装依頼に使います。

このMVPで生成しないもの

  • API設計書は、人間による設計レビューやdocs転記に使います。
  • MCP tools/resources/promptsは、AIエージェントへ公開する操作・参照範囲・定型指示の設計候補です。
  • 完全動作するMCPサーバー
  • DB永続化やマイグレーション
  • 認証・認可の本格実装、外部LLM API連携、本番デプロイ作業
