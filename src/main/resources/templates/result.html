おすすめの読み順

  1. まず入力サマリーで、どの業務要件から生成されたかを確認します。
  2. RESTエンドポイント一覧で、人間向けAPI候補を確認します。
  3. MCP tools/resources/promptsで、AIエージェントに公開する操作候補を確認します。
  4. API/MCP対応表で、人間向けAPIとAI向け操作入口の対応を確認します。
  5. セキュリティ・承認・監査ログ注意点で、危険操作や人間確認が必要な箇所を確認します。
  6. Markdown設計書やAI実装指示書を、レビューやCodex等への実装依頼に使います。

出力物の見方

  • API設計書は、人間による設計レビューやdocs転記に使います。
  • MCP tools/resources/promptsは、AIエージェントへ公開する操作・参照範囲・定型指示の設計候補です。
  • API/MCP対応表は、人間向けAPIとAI向け操作入口の対応を確認するための表です。
  • AI実装指示書は、APIM for Springを実装するためではなく、生成された設計候補をCodex等の実装支援AIへ渡し、対象業務アプリケーションの実装につなげるための成果物です。

このMVPで生成しないもの

  • 完全動作するMCPサーバー
  • DB永続化やマイグレーション
  • 認証・認可の本格実装
  • 外部LLM API連携
  • 本番デプロイ作業やRender公開作業
