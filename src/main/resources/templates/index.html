API + MCP Blueprint Compiler for Spring

選択された構造化要素から、API設計とMCP設計の候補を生成します。

初期MVPの位置づけ

APIM for Spring は、自由文を意味理解するAIではなく、選択された業務ドメイン・利用者・操作種別から Spring REST API / MCP設計候補を組み立てる静的ルールベースMVPです。

初期MVPで生成するもの

  • API設計候補
  • MCP tools / resources / prompts 候補
  • API/MCP対応表
  • セキュリティ・承認・監査ログ注意点
  • Markdown設計書 / AI実装指示書

初期MVPで生成しないもの

  • 自由文からの業務ルール自動抽出
  • 完全動作するMCPサーバー
  • DB永続化
  • 外部LLM API連携
ヘルプ

1. 対象と利用者

対象システム種別を選ぶと、標準ドメイン・利用者・操作種別の初期案を自動投入します。投入後も各チェック項目は自由に調整できます。

カテゴリ別ドメイン候補

複数の業務ドメインを選択すると、対象ドメイン欄へ自動反映します。必要に応じて対象ドメイン欄を直接編集できます。

2. 操作種別

APIMは、ここで選択された操作種別をもとにAPI/MCP候補を定型生成します。

必要な操作（必須）

AIアシスタントに許可したい操作（必須）

AIに禁止する操作

3. 承認・監査・権限

読み取り専用操作
書き込み許可操作
承認必須操作
監査ログが必要な操作

4. 補足情報

補足情報は出力文書へ反映されますが、現時点では自由文をAIのように意味解析して業務モデルを抽出するものではありません。
