API + MCP Blueprint Compiler for Spring

選択された構造化要素から、API設計とMCP設計の候補を生成します。

初期MVPの位置づけ

APIM for Spring は、自由文を意味理解するAIではなく、選択された業務ドメイン・利用者・操作種別から Spring REST API / MCP設計候補を組み立てる静的ルールベースMVPです。

初期MVPで生成するもの

  • API設計候補
  • MCP tools / resources / prompts 候補
  • API/MCP対応表
  • セキュリティ・承認・監査ログ注意点
  • Markdown設計書 / AI実装指示書

初期MVPで生成しないもの

  • 自由文からの業務ルール自動抽出
  • 完全動作するMCPサーバー
  • DB永続化
  • 外部LLM API連携
ヘルプ

1. 対象と利用者

対象システム種別プリセット

複数の対象システム種別を選ぶと、各システムに含まれる標準ドメイン・利用者・操作種別の初期案を合成して自動投入します。投入後も各チェック項目は自由に調整できます。

カテゴリ別ドメイン候補

ドメイン選択はこのカテゴリ別候補を正本とします。複数の業務ドメインを選択すると、対象ドメイン欄へ自動反映します。必要に応じて対象ドメイン欄を直接編集できます。

人事・総務

社員・組織・勤怠・申請など、社内管理系の業務ドメインです。

販売・EC

顧客・注文・商品・在庫・請求・決済・配送など、販売活動に関する業務ドメインです。

承認・統制

承認、通知、権限、監査ログ、契約など、統制・ガバナンスに関する横断ドメインです。

保守・サポート

問い合わせ、修理依頼、保守契約、FAQなど、顧客・利用者サポートに関する業務ドメインです。

ナレッジ・文書

文書、FAQ、議事録、検索・要約など、知識活用に関する業務ドメインです。

開発・運用

開発タスク、障害、リリースなど、開発・運用プロセスに関する業務ドメインです。

カテゴリ別ドメイン候補の選択結果を確認するための欄です。候補にないドメイン名の手動補正にも利用できます。
