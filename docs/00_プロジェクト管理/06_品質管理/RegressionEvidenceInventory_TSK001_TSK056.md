# TSK-001〜TSK-056 回帰証跡棚卸し

## 1. 位置づけ

本書は、TSK-068のPhase 1成果物として、既存TSK-001〜TSK-056の回帰証跡要否を棚卸ししたものである。

目的は、全件に機械的に自動テストを追加することではなく、各TSKの性質に応じて、自動回帰テスト、メタテスト、静的検査、手動確認証跡、対象外根拠、後続TSK化のいずれで担保するかを明確にすることである。

## 2. 棚卸し分類サマリ

| 分類 | 件数 |
|---|---:|
| 手動確認証跡で十分 | 8 |
| 手動確認証跡または静的検査 | 5 |
| 自動回帰テスト必須 | 21 |
| 静的検査または手動確認証跡 | 22 |

## 4. 評価

TSK-001〜TSK-056には、実装・生成ロジック・UI導線・公開準備・運用規程・ドキュメント整理が混在する。

そのため、全件に同一粒度の自動テストを追加するのは過剰である。一方、生成ロジック、UI導線、複数ドメイン対応、禁止語・旧仕様再発に関わる項目は、自動回帰テストまたは既存テストでの担保根拠が必要である。

本棚卸しにより、少なくとも各TSKに対して「どの証跡方式で担保するか」を追跡可能にした。
