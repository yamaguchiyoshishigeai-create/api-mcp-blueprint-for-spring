# TSK-038 ChatExec2ローカル詳細結果ディレクトリをgitignore標準化する

- ID: TSK-038
- 件名: ChatExec2ローカル詳細結果ディレクトリをgitignore標準化する
- 状態: 解決済み
- 優先度: High
- 主担当: ChatGPT(リポジトリ編集)
- 関連文書: `docs/00_プロジェクト管理/05_横断運用規程/ChatExec2方式.md`

## 背景

ChatExec2方式では、GitHub Issue/PRコメントへサニタイズ済みサマリを投稿し、ChatGPTは原則としてそのサマリを確認して次工程を判断する。

一方で、詳細ログや補助的な調査結果をローカルに残す必要があるため、対象リポジトリ配下に `.chatexec2/` ディレクトリを作成する運用が発生した。

`.chatexec2/` 配下のファイルはローカル補助ログであり、通常の成果物ではない。Git管理対象にすると、Sourcetree等のGUI上で未追跡ファイルとして表示され続け、誤コミットや視認ノイズの原因になる。

## 対応内容

- `.chatexec2/` をChatExec2のローカル詳細結果ディレクトリとして定義した。
- ChatGPTが通常確認すべき正規結果はGitHub Issue/PRコメントのサニタイズ済みサマリであることを明記した。
- `.chatexec2/` は失敗時・詳細調査時の補助ログとして扱うことを明記した。
- `.chatexec2/` 配下をGit管理対象外とする方針を明記した。
- `.gitignore` に `.chatexec2/` を追加した。

## 対象外

- 既存ローカル `.chatexec2/` ファイルの削除
- GitHub Issueコメントの削除
- ChatExec2テンプレート実装
- アプリケーションコード変更

## 完了条件

- `.chatexec2/` の位置づけが仕様書に明記されている。 → 完了
- 通常確認先がGitHub Issue/PRコメントであることが仕様書に明記されている。 → 完了
- `.chatexec2/` がGit管理対象外であることが仕様書に明記されている。 → 完了
- `.gitignore` に `.chatexec2/` が登録されている。 → 完了
