# TSK-039 AI作業分担方針を横断運用規程として仕様化する

- ID: TSK-039
- 件名: AI作業分担方針を横断運用規程として仕様化する
- 状態: 解決済み
- 優先度: High
- 主担当: ChatGPT(リポジトリ編集)
- 関連文書: `docs/00_プロジェクト管理/05_横断運用規程/AI作業分担方針.md`

## 背景

Codex作業が推奨される実装タスクであっても、いきなりCodexへ丸投げするのではなく、先にChatGPTが実装境界、スコープ、完了条件、後続TSKとの切り分けを整理することで、作業粒度を小さく保ち、越境実装やレビュー不能な大差分を防ぎやすくなる。

また、今後はCodexに限らず、Gemini、GitHub Copilot等の他の実装支援AIを利用する可能性がある。そのため、Codex固有の分担方針ではなく、より一般化したAI作業分担方針として横断運用規程へ仕様化する。

## 対応内容

- `AI作業分担方針.md` を横断運用規程として追加した。
- 作業主体を `ユーザー(人)`、`ChatGPT(会話内)`、`ChatGPT(リポジトリ編集)`、`実装支援AI` に分類した。
- Codex、Gemini、GitHub Copilot等を実装支援AIとして一般化した。
- 実装支援AI推奨タスクであっても、まずChatGPTによる境界定義・スコープ分割・完了条件整理を優先検討する方針を明記した。
- `ChatGPT(リポジトリ編集)+実装支援AI最小実装方式` を標準優先案として明記した。
- TSK分割・越境防止方針を明記した。

## 対象外

- 実装支援AI用テンプレートの実装
- Codex/Gemini/Copilotの具体的な利用手順書作成
- アプリケーションコード変更
- CI変更

## 完了条件

- AI作業分担方針が横断運用規程として追加されている。 → 完了
- 実装支援AI推奨時の優先検討ルールが明記されている。 → 完了
- ChatGPT(リポジトリ編集)+実装支援AI最小実装方式が明記されている。 → 完了
- Codex以外のAI利用も視野に入れた一般化表現になっている。 → 完了
