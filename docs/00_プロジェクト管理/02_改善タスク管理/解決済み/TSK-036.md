# TSK-036 ChatExec2方式にWindowsエクスプローラー実行UXを追加する

- ID: TSK-036
- 件名: ChatExec2方式にWindowsエクスプローラー実行UXを追加する
- 状態: 解決済み
- 優先度: High
- 主担当: ChatGPT(リポジトリ編集)
- 関連文書: `docs/00_プロジェクト管理/02_改善タスク管理/ChatExec2方式.md`

## 背景

Windows環境では、PowerShell実行ポリシーや文字コード差異により、`.ps1` や日本語を含む `.cmd` の実行がユーザー操作上の負担になることがある。

ChatExec2方式では、ローカル実行の安全性を保ちつつユーザー操作を最小化することを目的としているため、Windowsではエクスプローラー上でダウンロード済みスクリプトをマウスクリックまたはダブルクリックして実行できる運用を明確化する必要がある。

## 対応内容

- Windows環境ではエクスプローラー上でのクリック／ダブルクリック実行UXを重視する方針を追加した。
- Windows向けChatExec2スクリプトでは、必要に応じて `JOB_ID` 付きの単一 `.cmd` ファイルを配布候補とする方針を追加した。
- `.cmd` と `.ps1` の2ファイル同時配布を標準採用しない方針を追加した。
- PowerShell処理が必要な場合も、可能な範囲で単一 `.cmd` 内からPowerShellを呼び出す、または単一 `.ps1` を提示する方針を追加した。
- ChatGPT側の案内ルールと目的にもWindows単一ファイル実行UXを反映した。

## 対象外

- ChatExec2用 `.cmd` テンプレートの実装
- 既存CIの変更
- アプリケーションコード変更
- GitHub CLI認証方式の変更
