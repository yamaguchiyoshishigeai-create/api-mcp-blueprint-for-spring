# TSK-012 タスク採番方針をTSK正規IDへ是正する

- ID: TSK-012
- 件名: タスク採番方針をTSK正規IDへ是正する
- 状態: 解決済み
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

本リポジトリでは、Spring-Tool-Development-Template由来の改善タスク管理として `TSK-###` が採番されていた。

一方で、作業の進行中に `APIM-###` というプロジェクト名由来の独自採番が作業テーマ名・課題IDのように使われ、`TSK-###` と二重化した。

## 原因

テンプレートで `TSK-###` を正規タスクIDとして使う前提だったにもかかわらず、ChatGPTが `APIM-###` を独自に作成し、課題採番のように扱ったことが直接原因である。

## 対応内容

- 正規タスクIDを `TSK-###` と明記する。
- `APIM-###` の新規タスク採番を禁止する。
- `APIM` はプロジェクト名・説明上の名称としてのみ使用する。
- `課題管理ID体系.md` をTSK正規ID方針へ是正する。
- `旧TSK対応表.md` を `APIM呼称とTSK対応表` として再整理する。
- `改善タスク課題一覧.md` にTSK正規ID方針を追記する。

## 完了条件

- 正規タスクIDが `TSK-###` であることが明文化されている。
- `APIM-###` の新規タスク採番禁止が明文化されている。
- 今後の新設リポジトリで同じ混乱を防ぐため、Spring-Tool-Development-Templateへ反映すべき方針が整理されている。
## 解決内容

TSK-012として、APIM for Spring側のタスク採番方針を TSK-### 正規IDへ是正した。

主な反映内容:

- 正規タスクIDを TSK-### と明記した。
- APIM-### の新規タスク採番禁止を明文化した。
- APIM はプロジェクト名・説明上の名称としてのみ使用する方針へ整理した。
- 課題管理ID体系.md をTSK正規ID方針へ是正した。
- APIM呼称とTSK対応表 として過去呼称との対応を整理した。
- 改善タスク課題一覧.md にTSK正規ID方針を反映した。
- Spring-Tool-Development-Template側にもTSK-013として同方針を反映し、PR #8およびPR #9でmainへmerge済み。
