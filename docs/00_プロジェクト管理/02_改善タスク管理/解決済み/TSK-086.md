# TSK-086 既存JavaScript配置・依存関係調査

状態: 解決済み

## 分類

- 登録分類: investigation
- 優先度: Medium
- MVP整合性: MVP内
- 発生元: evaluation-recheck-20260526

## 目的

インラインJavaScript外出しに先立ち、既存JSの配置、画面依存、復元処理への影響を確認する。

## 完了条件

- 外出し可能な範囲と分割が必要な範囲が整理されている。
- チェック復元再発防止観点が明記されている。

## 調査結果

### 1. `external-ai-bridge.html`

対象ファイル:

- `src/main/resources/templates/external-ai-bridge.html`

確認したインラインJavaScript:

- `insertFreeTextSample(sampleText)`
- `clearFreeText()`

主な依存:

- `#freeTextInput`
- `#freeText`
- `textarea[name="freeText"]`
- サンプルボタンの `data-sample`
- サンプルボタンの `onclick="insertFreeTextSample(this.dataset.sample)"`
- 一括消去ボタンの `onclick="clearFreeText()"`

外出し可否:

- 外出し可能。
- Thymeleaf式への直接依存はなく、DOM依存のみ。
- 関数名はHTML上の `onclick` から参照されているため、外出し時は `window.insertFreeTextSample` / `window.clearFreeText` として公開するか、HTML側を `data-action` + `addEventListener` 方式へ変更する必要がある。

注意点:

- サンプル追記時に既存自由文へ `。また、` で追記する挙動があるため、TSK-075ではこの既存挙動を維持する。

### 2. `external-ai-prompt.html`

対象ファイル:

- `src/main/resources/templates/external-ai-prompt.html`

確認したインラインJavaScript:

- `switchJsonInputMode(mode)`
- `DOMContentLoaded` 時の初期表示切替
- `copyGeneratedPrompt()`

主な依存:

- `#jsonPastePanel`
- `#jsonFilePanel`
- `input[name="jsonInputMode"]`
- `#externalAiPromptText`
- `#copyStatus`
- `navigator.clipboard.writeText`
- fallbackとして `document.execCommand('copy')`
- radio inputの `onchange="switchJsonInputMode('file')"` / `onchange="switchJsonInputMode('paste')"`
- コピーボタンの `onclick="copyGeneratedPrompt()"`

外出し可否:

- 外出し可能。
- Thymeleaf式への直接依存はなく、DOM依存とClipboard API依存が中心。
- HTML上の `onclick` / `onchange` から参照されているため、外出し時は関数を `window` へ公開するか、イベントリスナー方式へ段階移行する。

注意点:

- Clipboard APIが使えないブラウザ向けのfallbackが実装済みであり、外出し後も維持する。
- `copyFeedbackTimer` は現状 `copyGeneratedPrompt()` 内のローカル変数で、呼び出しごとに初期化される。外出し時に挙動を変えない場合は現状維持でよいが、連打時のタイマー管理を改善する場合は別TSK扱いが妥当。

### 3. `index.html`

対象ファイル:

- `src/main/resources/templates/index.html`

確認したインラインJavaScript:

- `th:inline="javascript"` の大きなスクリプトブロック
- `sampleBusinessRequirements`
- `restoredSystemTypes`
- `restoredRelatedDomains`
- `systemTypePresets`
- サンプル投入、チェック項目同期、全選択/全解除、復元処理系の関数群

主な依存:

- Thymeleafインライン値:
  - `sampleBusinessRequirements`
  - `blueprintInput.systemTypes`
  - `blueprintInput.relatedDomains`
- 多数の `data-target` チェックボックス
- 将来LLM抽出レイヤー用のhidden/aria-hidden領域
- チェック式入力フォームの復元状態
- `fillSample(...)`
- `clearSample()`
- `setAllChecked(...)`
- `applySystemTypePresets()`
- `syncSelectedDomainsToTarget()`

外出し可否:

- 一括外出しは高リスク。
- `th:inline="javascript"` によるサーバー側値埋め込みがあるため、TSK-075では次のように段階分割するのが安全。
  1. Thymeleaf値注入だけをHTML側に残す。
  2. 純粋関数、DOM操作関数、プリセット処理関数を外部JSへ移す。
  3. HTMLから外部JSへ渡す初期値は `window.APIM_CHECK_INPUT_STATE` 等の単一オブジェクトにまとめる。

注意点:

- チェック復元再発防止の中心対象は `index.html`。
- `restoredSystemTypes` / `restoredRelatedDomains` の復元挙動を壊さないことをTSK-075の最重要受入条件にする。
- `data-target` 属性名を変更しないこと。
- `future-llm-template` 内のtextareaはサーバー送信用のhidden相当領域として使われているため、DOM操作対象から誤って除外または削除しないこと。

### 4. `result.html`

対象ファイル:

- `src/main/resources/templates/result.html`

確認結果:

- 主要な導線は通常のリンクとThymeleaf表示で構成されている。
- TSK-073で追加された結果サマリーはHTML/CSS中心であり、TSK-075のJavaScript外出し主対象ではない。

## TSK-075への推奨分割

### Phase 1: 低リスク外出し

対象:

- `external-ai-bridge.html`
- `external-ai-prompt.html`

推奨新規JS:

- `src/main/resources/static/js/external-ai-bridge.js`
- `src/main/resources/static/js/external-ai-prompt.js`

方針:

- 既存HTMLの `onclick` / `onchange` を大きく変えず、まずは関数を `window` に公開して外出しする。
- 低リスクに動作同等性を確認する。

### Phase 2: チェック式入力JSの分割準備

対象:

- `index.html`

推奨新規JS:

- `src/main/resources/static/js/check-input.js`

方針:

- HTML側には初期値注入だけを残す。
- 例:
  - `window.APIM_CHECK_INPUT_STATE = { sampleBusinessRequirements, restoredSystemTypes, restoredRelatedDomains }`
- プリセット定義、同期処理、全選択/全解除、サンプル投入処理は外部JSへ移す。

### Phase 3: イベントリスナー方式への段階移行

対象:

- HTML上の `onclick` / `onchange`

方針:

- Phase 1/2後、必要に応じて `data-action` / `data-sample-key` 等へ移行する。
- ただしTSK-075の初回では、動作維持を優先し、HTMLイベント属性を残したまま関数外出しでもよい。

## チェック復元再発防止観点

TSK-075で必ず確認すること:

1. サンプル投入後、対象システム種別、カテゴリ別ドメイン候補、必要操作、AI許可操作、承認必須操作、監査ログ対象が期待どおり反映される。
2. JSON取り込み後または編集画面復元時に、`restoredSystemTypes` / `restoredRelatedDomains` が消えない。
3. `data-target` に紐づくチェックボックス同期が壊れない。
4. `future-llm-template` 内のtextareaへ最終送信用テキストが反映される。
5. `external-ai-bridge.html` のサンプルボタンと一括消去が動く。
6. `external-ai-prompt.html` のJSON入力方法切替、プロンプトコピー、コピー結果表示が動く。
