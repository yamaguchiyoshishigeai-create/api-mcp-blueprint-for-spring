# TSK-067 APIM側に残る旧運用記述を中枢参照構成へ整理する

- ID: TSK-067
- 件名: APIM側に残る旧運用記述を中枢参照構成へ整理する
- 状態: 解決済み
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集) / ChatExec2
- 起票日: 2026-05-18
- 解決日: 2026-05-18
- 提案名: APIM-OPS-SINGLE-SOURCE-CLEANUP-01

## 背景

APIM for Spring は、`chatgpt-ops-rules` を共通運用ルールの単一正本として参照する構成へ移行済みである。

一方で、`改善タスク課題一覧.md` の上部には、外部実行結果ファイル方針、待ちフェーズ運用方針、squash merge後ブランチ整理方針、順次タスクmergeゲート方針、ChatExec2方式方針、AI作業分担方針など、旧運用記述が残っていた。

これらをAPIM側に残すと、`chatgpt-ops-rules` の現行正本と重複・衝突し、どちらが正本か不明瞭になる。

## 実施内容

- `改善タスク課題一覧.md` から旧運用ルール本文を除去し、運用ルール正本参照方針へ置換した。
- 除去した旧運用記述を `docs/90_アーカイブ/旧横断運用規程/改善タスク課題一覧旧運用記述-20260518.md` へ分離した。
- 旧横断運用規程アーカイブREADMEへ、当該アーカイブの参照導線を追加した。
- TSK-067個票を解決済みとして作成した。

## 完了条件

- APIM側の改善タスク課題一覧に、ChatExec2、CI、PR、merge、cleanup、AI作業分担等の共通運用ルール本文が残っていない。
- 共通運用ルールの単一正本が `chatgpt-ops-rules` であることが明記されている。
- 旧運用記述が履歴参照用アーカイブへ分離されている。
- 旧運用記述は現行正本ではないことが明記されている。
- TSK-067が改善タスク課題一覧へ登録されている。

## 非対象

- `chatgpt-ops-rules` 側のルール本文改定。
- APIM固有の業務仕様、実装仕様、Render公開準備文書の変更。
- Java実装、テスト、生成ロジックの変更。

## 検証

- `git diff --check`
- 変更対象ファイルの存在確認
- `改善タスク課題一覧.md` に旧運用見出しが残っていないことの確認
- `chatgpt-ops-rules` 単一正本参照文言の確認
