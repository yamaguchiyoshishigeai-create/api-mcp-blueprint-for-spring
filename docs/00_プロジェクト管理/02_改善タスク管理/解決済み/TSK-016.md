# TSK-016 外部実行補助ログのgitignore標準化を追加する

- ID: TSK-016
- 件名: 外部実行補助ログのgitignore標準化を追加する
- 状態: 解決済み
- 優先度: Medium
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

TSK-015-Aのローカルスモーク確認では、Spring Boot起動確認用に `ChatExec-springboot.out` と `ChatExec-springboot.err` が生成された。

`ChatExec.result` は `.gitignore` に登録済みだったが、補助的な標準出力・標準エラーログは未登録だったため、`git status --porcelain=v1 --untracked-files=all` に未追跡ファイルとして表示された。

## 対応内容

- `.gitignore` に `ChatExec-*.out` を追加する。
- `.gitignore` に `ChatExec-*.err` を追加する。
- `.gitignore` に `CodexExec-*.out` を追加する。
- `.gitignore` に `CodexExec-*.err` を追加する。
- 改善タスク課題一覧の外部実行結果ファイル方針に、付随する標準出力・標準エラーログもコミット対象にしない旨を追記する。

## 完了条件

- 外部実行補助ログが通常の `git status` に出ない。
- `ChatExec.result` / `CodexExec.result` だけでなく、周辺ログもコミット対象外として扱われる。
- 台帳にTSK-016が解決済みとして登録されている。
