# TSK-053 運用ルール改定の横展開要否を判断する

## 状態

解決済み

## 優先度

Medium

## 主担当候補

ChatGPT(会話内) / ChatGPT(リポジトリ編集)

## 背景

APIM for Springでは、TSK-047、TSK-048、TSK-050により、以下の運用ルールを追加・明文化した。

1. ローカル一時ファイルとルート直下整理方針。
2. CIポーリング終了条件固定方針。
3. Merge後cleanup・local sync自動統合方針。

これらはいずれもAPIM for Spring固有の問題から発生したが、ChatExec2方式、Codex投入、CI確認、branch cleanup、local syncを利用する他リポジトリにも適用可能な横断運用ルールである。

過去の横展開対象として、`Spring-Tool-Development-Template`、`Q-Scout-for-Spring`、`portfolio` が挙がっている。

## 対応結果

1. APIM for Springで追加されたTSK-047 / TSK-048 / TSK-050系ルールを棚卸しした。
2. `Spring-Tool-Development-Template` の既存運用規程と直近横展開PRを確認した。
3. `Q-Scout-for-Spring` の既存運用規程と直近横展開PRを確認した。
4. `portfolio` の軽量版運用ルールHub横展開状況を確認した。
5. 3リポジトリとも `部分反映` が妥当と判断した。
6. 判断結果を `運用ルール改定横展開判断結果.md` に記録した。
7. 後続候補として、TSK-054 / TSK-055 / TSK-056 を分割候補として整理した。

## 判断結果

| リポジトリ | 判断 | 後続方針 |
|---|---|---|
| `Spring-Tool-Development-Template` | 部分反映 | テンプレート向けに抽象化して後続タスクで反映する |
| `Q-Scout-for-Spring` | 部分反映 | Q-Scout既存運用規程と整合させて後続タスクで反映する |
| `portfolio` | 部分反映 | 公開安全性条件を維持した軽量版として後続タスクで反映する |

## 実施しなかったこと

- 本タスク内での無条件横展開。
- 各リポジトリへの即時PR作成。
- 実装コード変更。
- CI workflow変更。
- APIM for Spring以外のリポジトリ構成を確認せずに文書をコピーすること。

## 完了条件確認

- 横展開候補リポジトリごとの判断結果を整理済み。
- 3リポジトリとも `部分反映` として判断済み。
- 横展開が必要な場合の後続タスク分割方針を整理済み。
- 判断結果を横断運用規程に記録済み。
- PRのCI successとmain mergeをもって完了とする。
