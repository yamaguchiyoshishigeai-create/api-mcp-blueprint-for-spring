# TSK-075 インラインJavaScript外出し

状態: 解決済み

## 分類

- 登録分類: immediate / next
- 優先度: Medium
- MVP整合性: MVP内
- 発生元: evaluation-recheck-20260526

## 目的

HTMLテンプレートの保守性を改善し、再発修正やUI変更時の影響範囲を読みやすくする。

## 想定変更対象

- HTMLテンプレート
- static JSファイル

## 実装概要

- 既存のインラインJavaScript配置をTSK-086で事前調査した。
- 影響範囲が小さいものから外部JS化した。
- 画面固有ロジックを以下のstatic JSへ分離した。

## 完了内容

### Phase 1: 外部AIブリッジ系JavaScript外出し

対象:

- `src/main/resources/templates/external-ai-bridge.html`
- `src/main/resources/templates/external-ai-prompt.html`
- `src/main/resources/static/js/external-ai-bridge.js`
- `src/main/resources/static/js/external-ai-prompt.js`
- `src/test/java/com/example/apim/controller/ExternalAiBridgeControllerTest.java`

内容:

- `insertFreeTextSample()` と `clearFreeText()` を `external-ai-bridge.js` へ移動した。
- `switchJsonInputMode()`、`copyGeneratedPrompt()`、Clipboard API fallback、初期表示切替を `external-ai-prompt.js` へ移動した。
- 既存のHTMLイベント属性から呼び出せるよう、必要な関数を `window` へ公開した。
- テスト期待値を、HTML内のインラインJS本文ではなく外部JS参照を確認する仕様へ更新した。

### Phase 2: チェック式入力画面JavaScript外出し

対象:

- `src/main/resources/templates/index.html`
- `src/main/resources/static/js/check-input.js`
- `src/test/java/com/example/apim/controller/BlueprintControllerTest.java`

内容:

- `index.html` には `window.APIM_CHECK_INPUT_STATE` によるThymeleaf値注入のみを残した。
- プリセット定義、チェック復元、チェック同期、サンプル投入、submit前同期処理を `check-input.js` へ移動した。
- `fillSample()`、`clearSample()`、`setAllChecked()`、`syncSelectedDomainsToTarget()` など、既存HTMLイベント属性から呼び出す必要がある関数を `window` へ公開した。
- テスト期待値を、HTML内のJavaScript実装本文ではなく `/js/check-input.js` と `window.APIM_CHECK_INPUT_STATE` を確認する仕様へ更新した。

## 完了条件への対応

- 対象範囲のインラインJavaScript整理: 完了。
- チェック復元、サンプル入力、コピー導線など既存挙動維持: テスト期待値更新と `mvnw.cmd test` により確認。
- 影響が大きい場合の分割TSK化: TSK-086調査結果に基づきPhase 1 / Phase 2へ分割して実施。追加TSK切り出しは不要と判断。

## 検証

- Phase 1では、低リスクな外部AIブリッジ系JSを外出し後、`mvnw.cmd test` がPASS。
- Phase 2では、Test Firstとして `BlueprintControllerTest` の期待値を外部JS仕様へ先に更新し、対象テストのREDを確認後、実装を変更。
- Phase 2実装後、`mvnw.cmd test` がPASS。
- GitHub上で以下を確認済み。
  - `index.html` は `window.APIM_CHECK_INPUT_STATE` と `/js/check-input.js` を参照。
  - `check-input.js` にプリセット定義、復元処理、同期処理、サンプル投入処理を配置。
  - `BlueprintControllerTest` は外部JS参照仕様へ更新。
