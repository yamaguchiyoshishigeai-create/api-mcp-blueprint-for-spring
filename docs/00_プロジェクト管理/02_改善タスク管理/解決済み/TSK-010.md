# TSK-010 Domain Vocabulary / Resource Naming を改善する

- ID: TSK-010
- 件名: Domain Vocabulary / Resource Naming を改善する
- 状態: 解決済み
- 優先度: High
- 主担当候補: Codex

## 背景

APIM-013の生成品質レビューで、`domain-items` / `DomainItem` 系の汎用名に寄りやすい課題が確認された。

## 対応内容

日本語ドメイン名を、業務固有の英語resource名、DTO名、API path、MCP tool名へ変換できるように改善する。

## 完了条件

3サンプル（備品貸出管理、社内申請ワークフロー、ナレッジ検索・要約）で、主要生成名が `domain-items` / `DomainItem` に落ちず、業務固有語彙が反映されること。

## 解決内容

APIM-014としてPR #11で実装され、mainへmerge済み。

主な反映内容:

- `DomainNameNormalizer` に固定語彙マッピングを追加
- `DomainNameNormalizerTest` を追加
- `BlueprintGenerationServiceTest`、`McpDesignGeneratorTest`、`ApiDesignGeneratorTest` を更新
- 備品貸出管理で `/api/equipment`、`Equipment*` DTO、MCP tool名のEquipment系語彙を確認
- 社内申請ワークフローで `/api/applications`、`Application*` DTO、MCP tool名のApplication系語彙を確認
- ナレッジ検索・要約で `/api/knowledge-articles`、`KnowledgeArticle*` DTO、MCP tool名のKnowledgeArticle系語彙を確認
- Maven Wrapper testおよびGitHub ActionsがPASS
