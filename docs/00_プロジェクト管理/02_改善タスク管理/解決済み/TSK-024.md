# TSK-024 squash merge後の作業ブランチ削除・prune運用を標準化する

- ID: TSK-024
- 件名: squash merge後の作業ブランチ削除・prune運用を標準化する
- 状態: 解決済み
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

PRをsquash mergeした場合、作業ブランチ上の個別コミットIDはmainの祖先にならない。

また、GitHubコネクタでmergeした場合は、作業ブランチ削除が自動実行されない。

## 対応内容

改善タスク課題一覧に、squash merge後の作業ブランチ整理方針を追加した。

主なルールは以下である。

- PRをsquash mergeした後は、作業ブランチを削除対象とする。
- GitHubコネクタでmergeした場合、作業ブランチ削除は自動実行されない前提で扱う。
- merge後にリモート作業ブランチ削除を行う。
- ローカル環境では `git fetch origin --prune` を実行する。
- GUI上の枝残りだけで未統合とは判断しない。

## 完了条件

- squash merge後の作業ブランチ削除方針が明文化されている。
- prune運用が明文化されている。
- GUI表示に対する判断基準が明文化されている。
