# TSK-018 生成成果物Markdownをダウンロード可能にする

- ID: TSK-018
- 件名: 生成成果物Markdownをダウンロード可能にする
- 状態: 解決済み
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

APIM for Spring は、API/MCP設計書とAI実装指示書を生成することを目的としている。

現行UIでは、生成結果画面からMarkdown設計書とAI実装指示書をプレビューできるが、成果物ファイルとして直接ダウンロードする導線が不足していた。

## 対応内容

- `GET /blueprint/download` を追加し、`api-mcp-blueprint.md` を添付ファイルとして返す。
- `GET /blueprint/implementation-instructions/download` を追加し、`implementation-instructions.md` を添付ファイルとして返す。
- 生成結果画面にMarkdown設計書ダウンロードリンクを追加する。
- 生成結果画面にAI実装指示書ダウンロードリンクを追加する。
- Controllerテストにダウンロード正常系と未生成時404を追加する。

## 完了条件

- 生成後にMarkdown設計書を `api-mcp-blueprint.md` としてダウンロードできる。
- 生成後にAI実装指示書を `implementation-instructions.md` としてダウンロードできる。
- 未生成状態ではダウンロードendpointが404を返す。
- 既存プレビュー導線が維持される。
- CIが成功する。
