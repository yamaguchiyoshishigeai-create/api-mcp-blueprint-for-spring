# TSK-056 portfolioへTSK-047/048/050系運用ルールを軽量横展開する

## 状態

解決済み

## 優先度

Medium

## 主担当候補

ChatGPT(リポジトリ編集)

## 背景

TSK-053で、APIM for Springに追加されたTSK-047 / TSK-048 / TSK-050系運用ルールについて、関連リポジトリへの横展開要否を判断した。

`portfolio` はPR #14で軽量版の運用ルールHubとCodex投入ゲートを横展開済みである。ただし、公開ポートフォリオ用リポジトリであるため、Spring系リポジトリと同じ粒度の運用規程を無条件に追加するのは適切ではない。

CIやbranch cleanup、ChatExec2実行結果の扱いは有用だが、公開安全性条件を維持し、必要最小限の軽量版として反映する必要がある。

## 対応内容

1. `portfolio` の既存軽量版運用ルールHubを確認する。
2. TSK-047 / TSK-048 / TSK-050相当のうち、portfolioで必要な内容を抽出する。
3. 公開安全性条件、個人情報、実企業名、守秘情報の扱いと矛盾しない軽量版へ調整する。
4. 必要に応じて運用ルールHubから参照できるようにする。
5. PR作成、確認、main反映、merge後cleanupを行う。

## 実施しないこと

- APIM固有文書を無条件コピーすること。
- 公開ポートフォリオ本体の表示コンテンツ変更。
- 個人情報、実企業名、顧客名、内部システム名、守秘情報の追加。
- 実装コード変更。
- Spring系2リポジトリへの同時反映。

## 完了条件

- 公開安全性条件と矛盾していないこと。
