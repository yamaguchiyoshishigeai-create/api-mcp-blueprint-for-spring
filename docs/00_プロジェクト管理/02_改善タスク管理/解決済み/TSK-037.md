# TSK-037 ChatExec2方式に再配布ファイル名一意化と自己参照方針を追加する

- ID: TSK-037
- 件名: ChatExec2方式に再配布ファイル名一意化と自己参照方針を追加する
- 状態: 解決済み
- 優先度: High
- 主担当: ChatGPT(リポジトリ編集)
- 関連文書: `docs/00_プロジェクト管理/05_横断運用規程/ChatExec2方式.md`

## 背景

ChatExec2方式では、Windows向け `.cmd` をエクスプローラーからダブルクリック実行できるUXを重視している。

しかし、同一ファイル名で再配布すると、ブラウザやOSが ` (1)`、` (2)` などのサフィックスを自動付与する場合がある。この場合、スクリプト内で固定ファイル名を前提に自己再起動や自己参照を行うと、実際にダウンロード・実行されたファイル名と不一致になり、ウィンドウ保持や再起動処理が崩れる可能性がある。

## 対応内容

- ChatExec2方式で配布するスクリプトファイル名は、同一JOBであっても配布のたびに一意化する方針を追加した。
- `JOB_ID` に加えて `R01`、`R02`、`R03` などの配布版識別子を付ける方針を追加した。
- `JOB_ID` は論理ID、配布版識別子は物理ファイル名識別子として扱う方針を追加した。
- スクリプト内部で自身を再起動・参照する場合は、固定ファイル名ではなく実行中の自分自身の実ファイル名・実パスを使う方針を追加した。
- Windows `.cmd`、PowerShell、Bashでの代表的な自己参照方法を明記した。

## 対象外

- ChatExec2用テンプレート実装
- 既存Issueコメントの削除
- CI変更
- アプリケーションコード変更

## 完了条件

- 再配布ファイル名の一意化方針が明記されている。 → 完了
- 同一JOB再配布時にも前回と同じダウンロードファイル名を使わない方針が明記されている。 → 完了
- スクリプトが自身の固定想定名ではなく実ファイル名・実パスを参照する方針が明記されている。 → 完了
- Windows `.cmd` の `%~f0` 等の自己参照例が明記されている。 → 完了
