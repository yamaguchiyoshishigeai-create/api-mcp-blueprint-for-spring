# TSK-050 Merge後cleanup・local sync自動統合方針を明文化する

## 状態

解決済み

## 優先度

High

## 主担当候補

ChatGPT(リポジトリ編集)

## 関連PR

- PR #94: TSK-050 Merge後cleanup・local sync自動統合方針を明文化する

## 背景

PR squash merge後のremote branch cleanup、local prune、local main fast-forward syncは、順次タスクmergeゲート上の必須後続処理である。

しかし、従来の運用では、merge後のcleanupが必須工程であるにもかかわらず、ChatGPTがユーザーへ「進めてよいか」を確認して停止したり、cleanup用スクリプトとlocal sync用スクリプトを分割して提示したりする余地があった。

この結果、成功時でもユーザーが複数回 `.cmd` を実行し、結果を複数回貼る必要が発生した。

## 対応結果

1. merge後cleanupが必須工程である場合、確認待ちにせずChatExec2スクリプト作成まで自動で進めることを明文化した。
2. remote branch cleanup、local prune、local main fast-forward syncを原則1本のChatExec2スクリプトに統合することを明文化した。
3. 失敗時の停止条件と報告内容を明文化した。
4. cleanupとlocal syncを分割してよい例外条件を限定した。
5. 成功時のユーザー操作は1回のダブルクリックまたは単一コマンド実行を目標とすることを明文化した。

- 失敗時の停止方針、完了済み工程、未実施工程の報告方針が明記されている。
