# TSK-013 改善タスク管理の状態フォルダ保持ルールを追加する

- ID: TSK-013
- 件名: 改善タスク管理の状態フォルダ保持ルールを追加する
- 状態: 解決済み
- 優先度: Medium
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

TSK-008を未解決配下から解決済み配下へ移動した後、Windows環境の git pull 中に、空になった状態フォルダの処理で対話プロンプトが発生した。

状態フォルダは将来のタスク管理で再利用するため、空になっても保持する方針とする。

## 対応内容

- 未解決/ に .gitkeep を追加する。
- 解決中/ に .gitkeep を追加する。
- 確認待ち/ に .gitkeep を追加する。
- 保留/ に .gitkeep を追加する。
- 解決済み/ に .gitkeep を追加する。
- 改善タスク課題一覧に状態フォルダ保持方針を追記する。

## 完了条件

- 状態フォルダが空になってもGit管理上保持される。
- 将来タスク追加時に同じフォルダを再利用できる。
- Git操作時の不要な対話プロンプト発生リスクを低減できる。
