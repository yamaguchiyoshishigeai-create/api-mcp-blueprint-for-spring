## 背景

`chatgpt-ops-rules` が共通運用ルールの正本として整備され、TSK-009からTSK-012により、通常PR自動merge方針、ChatExec2 Windows bat標準、個票先行main反映ゲート、FullFlow bat一括実行方針が追加された。

一方、`api-mcp-blueprint-for-spring` 側には、過去の横断運用規程やリポジトリ固有運用が残っており、共通運用ルール正本との参照関係を明確化する必要があった。

## 目的

`api-mcp-blueprint-for-spring` に `chatgpt-ops-rules` への中枢参照を導入し、共通運用ルールとAPIM固有ルールの分離を明確化する。

## 実施したこと

1. `PROJECT_START_PROMPT.md` に `chatgpt-ops-rules` 参照を追加した。
2. `README.md` / `docs/README.md` に中枢参照導線を追加した。
3. `docs/00_プロジェクト管理/05_横断運用規程/00_運用ルール索引と実行ゲート.md` を中枢参照スタブへ薄型化した。
4. `docs/00_プロジェクト管理/05_横断運用規程/chatgpt-ops-rules中枢参照方針.md` を追加した。
5. APIM固有の業務仕様、設計生成系前提、実装仕様はAPIM側に残す方針を明記した。
6. APIM側に共通運用ルール本文を重複コピーしない方針を明記した。
7. 改善タスク課題一覧をTSK-060解決済みへ同期した。
