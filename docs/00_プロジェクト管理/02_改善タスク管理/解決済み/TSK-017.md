# TSK-017 Windows Git内部メンテナンス対話プロンプトを抑制する

- ID: TSK-017
- 件名: Windows Git内部メンテナンス対話プロンプトを抑制する
- 状態: 解決済み
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

Windows環境で `git pull` 実行中、Git内部の重複オブジェクト整理により `.git/objects/*` ディレクトリ削除確認が大量に発生した。

これは作業ツリーの未追跡ファイル問題ではなく、Git内部データベースの自動メンテナンスに起因する。

`.git/objects` は `.gitignore` の制御対象ではないため、`.gitignore` 追加では解決しない。

## 対応内容

- `scripts/setup-local-git-stable.ps1` を追加する。
- `origin/HEAD` の参照を自動修復する。
- リポジトリローカル設定として `gc.auto=0` を設定する。
- リポジトリローカル設定として `maintenance.auto=false` を設定する。
- リポジトリローカル設定として `gc.autoDetach=false` を設定する。
- 台帳にWindows Git安定化方針を追記する。

## 運用方針

自動GCと自動maintenanceを抑制し、必要時のみユーザーがVSCode、エクスプローラー、セキュリティスキャン等の影響を避けた状態で手動メンテナンスを行う。

## 完了条件

- Windows環境で大量の `(y/n)` 削除確認を誘発する自動メンテナンスを抑制できる。
- `.git/objects` を `.gitignore` では制御しない方針が明文化されている。
- ローカルセットアップスクリプトで再適用可能である。
