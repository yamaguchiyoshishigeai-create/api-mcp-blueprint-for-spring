# TSK-014 ChatExec結果ファイルのgitignore標準化を追加する

- ID: TSK-014
- 件名: ChatExec結果ファイルのgitignore標準化を追加する
- 状態: 解決済み
- 優先度: Medium
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

PowerShell外部実行方式では、実行結果を `ChatExec.result` に集約する運用を標準としている。

結果ファイルをリポジトリ外へ出力すると、場所が作業者環境依存になり、どのリポジトリの実行結果か分かりにくくなる。

また、過去作業では `ChatExec.result` が誤ってコミット対象に混入した。

## 対応方針

- 実行結果ファイルは、実行対象リポジトリのルートへ `ChatExec.result` として毎回上書き出力する。
- Codex連携用の実行結果ファイルは、実行対象リポジトリのルートへ `CodexExec.result` として毎回上書き出力する。
- `ChatExec.result` と `CodexExec.result` は `.gitignore` に登録し、コミット対象外とする。
- 過去に追跡対象になった場合は、`git rm --cached -f ChatExec.result CodexExec.result` で追跡対象から外す。

## 対応内容

- `.gitignore` に `ChatExec.result` と `CodexExec.result` を追加した。
- 改善タスク課題一覧へ、外部実行結果ファイル方針を追記した。
- 改善タスク課題一覧へTSK-014を追加した。

## 完了条件

- `ChatExec.result` と `CodexExec.result` が `.gitignore` に登録されている。
- 結果ファイルをリポジトリルートへ固定出力する方針が明文化されている。
- 結果ファイルをコミット対象にしない方針が明文化されている。
