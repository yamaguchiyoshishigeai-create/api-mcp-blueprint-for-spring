# TSK-008 Windows環境で spring-boot:run 起動失敗を調査する

- ID: TSK-008
- 件名: Windows環境で spring-boot:run 起動失敗を調査する
- 状態: 解決済み
- 優先度: Medium
- 主担当候補: Codex

## 背景

APIM-007のWindows手動確認で、Maven Wrapperによるtest、compile、package、jar起動は成功した。

一方で、spring-boot:run は main class を検出できずに失敗した。

## 確認済み事項

- `mvnw.cmd test`: PASS
- `mvnw.cmd clean compile`: PASS
- `target/classes/com/example/apim/ApimApplication.class`: 存在確認済み
- `mvnw.cmd package`: PASS
- jar起動: PASS
- `http://localhost:8080/`: 表示確認済み

## 調査対象

- Spring Boot Maven Plugin の run 実行時クラスパス
- Windows PowerShell / Maven Wrapper 経由の引数受け渡し
- OneDrive配下パスや日本語パスの影響
- mainClass 明示設定の要否

## 完了条件

- Windows環境で spring-boot:run が成功する、または
- spring-boot:run を非推奨として jar起動方式を正式手順とする判断を文書化する。

## 解決内容

2026-05-03に、リポジトリを `C:\academia\src\api-mcp-blueprint-for-spring` 配下へ移動した状態で再検証した。

確認結果:

- `mvnw.cmd clean test`: PASS
- `mvnw.cmd package`: PASS
- `target/classes/com/example/apim/ApimApplication.class`: 存在確認済み
- `mvnw.cmd spring-boot:run`: Tomcat started on port 8080 / Started ApimApplication まで到達
- `mvnw.cmd spring-boot:run "-Dspring-boot.run.main-class=com.example.apim.ApimApplication"`: Tomcat started on port 8080 / Started ApimApplication まで到達
- `mvnw.cmd spring-boot:run "-Dspring-boot.run.fork=false"`: Tomcat started on port 8080 / Started ApimApplication まで到達

上記の通り、現在の `C:\academia` 配下では `spring-boot:run` の main class 検出失敗は再現しなかった。

なお、各 `spring-boot:run` のexit codeは `Ctrl+C` により停止したため `-1` となったが、起動ログ上はサーバー起動に成功している。

判断:

- 旧事象は旧OneDrive配下パス、当時のPowerShell引数指定、または当時のローカル環境条件に起因していた可能性が高い。
- 現行パスでは `spring-boot:run` が利用可能であるため、TSK-008は解決済みとする。
- README上の既知課題記述は更新し、jar起動に加えて `spring-boot:run` も利用可能な手順として扱う。
