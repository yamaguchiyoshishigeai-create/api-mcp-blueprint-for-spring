# TSK-007 APIM for Spring に Maven Wrapper を追加する

- ID: TSK-007
- 件名: APIM for Spring に Maven Wrapper を追加する
- 状態: 解決済み
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

APIM-007の手動動作確認で、ユーザーPCに `mvn` コマンドが存在せず、ローカルで `mvn test` および `mvn spring-boot:run` を実行できなかった。

Q-Scout-for-Springには Maven Wrapper が存在していたが、APIM for Spring には未導入だったため、ローカルMaven未導入環境でも再現性高くテスト・起動できるようにする。

## 対応内容

- `mvnw` を追加する。
- `mvnw.cmd` を追加する。
- `.mvn/wrapper/maven-wrapper.properties` を追加する。
- READMEに Maven Wrapper を使った起動・テスト手順を追記する。
- GitHub Actionsの Maven test を Maven Wrapper 経由に変更する。
- `AI_REPO_RESULT.md` にAPIM-008の作業結果を追記する。

## 完了条件

- Windowsで `mvnw.cmd test` を実行できる。
- macOS/Linuxで `mvnw test` を実行できる。
- GitHub Actionsが Maven Wrapper 経由でテストを実行する。
- READMEに Maven Wrapper 手順が記載されている。
- PRが作成されている。

## 解決内容

APIM-008としてMaven Wrapper追加をPR #5でmainへmerge済み。Windows用Wrapper修正もPR #6でmainへmerge済み。APIM-007手動確認で `mvnw.cmd test`、`mvnw.cmd package`、jar起動を確認済みのため解決済みとする。

## 補足

Windows環境での `spring-boot:run` 起動失敗はTSK-008に分離して継続管理する。
