# TSK-062 旧横断運用規程ファイル群を中枢参照構成へ整理する

状態: 解決済み
優先度: High
主担当候補: ChatGPT(リポジトリ編集)
提案名: APIM-LEGACY-OPS-RULES-CLEANUP-02
起票日: 2026-05-10
解決日: 2026-05-10

## 背景

TSK-060により、`api-mcp-blueprint-for-spring` には `chatgpt-ops-rules` への中枢参照が導入された。

一方で、`docs/00_プロジェクト管理/05_横断運用規程/` 配下には、過去にAPIM側へ複製・蓄積された旧横断運用規程ファイル群がまだ残っていた。

Spring-Tool-Development-Templateでは、旧横断運用規程の詳細本文を現行ツリーから薄型化し、必要な履歴参照を `docs/90_アーカイブ/旧横断運用規程/README.md` に整理済みである。

APIM側も同様に、共通運用ルール本文を個別リポジトリ側へ重複保持しない構成へ整理する必要があった。

## 目的

`api-mcp-blueprint-for-spring` の旧横断運用規程ファイル群を棚卸しし、`chatgpt-ops-rules` を正本とする中枢参照構成へ整理する。

## 実施したこと

1. `docs/00_プロジェクト管理/05_横断運用規程/` 配下の旧詳細規程ファイル群を棚卸しした。
2. 共通運用ルール本文に該当する旧詳細規程をAPIM側の現行ツリーから削除した。
3. APIM側に残す文書を、入口文書、中枢参照方針、作業証跡管理、Codex連携運用に絞った。
4. 履歴参照用に `docs/90_アーカイブ/旧横断運用規程/README.md` を追加した。
5. 旧規程整理前commitをアーカイブREADMEに記録した。
6. 改善タスク課題一覧をTSK-062解決済みへ同期した。
