## 背景

TSK-031で正規化レイヤが導入され、TSK-032で生成成果物上のドメイン境界表示が追加され、TSK-033でAPI Generatorが主ドメインAPIと関連ドメイン参照APIの境界に対応した。

TSK-034では、MCP Generatorのtools / resources / prompts候補を、主ドメイン・関連ドメイン・横断操作の境界を意識した出力へ拡張した。

## 最小実装境界

TSK-034では、MCP設計生成において、主ドメインtools、関連ドメインresources、横断prompts、API/MCP対応表がドメイン境界を意識して確認できる出力へ拡張する範囲に限定した。

## TSK-034で実施したこと

- MCP Generatorに `NormalizedBlueprintInput` を受け取る複数ドメイン用生成経路を追加した。
- 主ドメインtools候補と関連ドメイン参照tools候補を出力上で区別できるようにした。
- MCP resources候補を主ドメインresourceと関連ドメインresourceに分けた。
- MCP prompts候補に横断利用場面、禁止事項、人間確認条件、センシティブ情報の扱いを反映した。
- API/MCP対応表のnotesへ、TSK-033の主ドメインAPI・関連ドメイン参照API境界、AI実行可否、承認要否、監査ログ要否を反映した。
- `BlueprintGenerationService` から、関連ドメインがある場合のみ複数ドメイン用MCP生成経路を使うようにした。
- 既存の単一ドメイン互換経路を維持し、旧入力 `targetDomain` のみでも既存のMCP設計候補を生成できるようにした。
- 表示追加と互換維持に関するテストを追加・更新した。
