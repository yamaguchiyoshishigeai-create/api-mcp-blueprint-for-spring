## 背景

現行の生成結果に含まれる「AI実装指示書」は、利用者が入力した業務要件と生成されたAPI/MCP設計候補をもとに、後続のAIまたは実装者へ実装を依頼するための成果物であるべきである。

しかし修正前の `ImplementationInstructionGenerator` は、冒頭で「APIM for Spring のMVPを段階実装する」と出力し、実装対象として入力フォーム、API/MCP候補生成、結果表示とプレビュー、`BlueprintController` などを扱っていた。

これは、生成対象の業務アプリケーションを実装するための指示書ではなく、APIM for Spring 自体を実装するための内部向け指示書になっていた。

## 目的

AI実装指示書を、APIM for Spring 自体の実装指示ではなく、生成されたREST API候補、DTO候補、Controller雛形、MCP tools/resources/prompts、API/MCP対応表、セキュリティ・承認・監査ログ注意点をもとに、対象業務アプリケーションを後続AIまたは実装者が実装するための指示書へ修正する。

## 実施したこと

- `ImplementationInstructionGenerator` の出力目的を、APIM for Spring本体の実装指示から、生成対象業務アプリケーション向けの実装支援AI指示へ変更した。
- 入力業務要件、対象システム種別、対象ドメイン、必要操作、AI許可操作、出力言語をAI実装指示書へ整理して出力するようにした。
- 生成済みREST API候補、DTO候補、Controller雛形、MCP tools/resources/prompts、API/MCP対応表、セキュリティ・承認・監査ログ注意点を、後続AIが使う実装材料として章立てした。
- `APIM for Spring のMVPを段階実装する` 等のAPIM内部実装文言を出力しないようにした。
- `result.html` のAI実装指示書説明を、生成された設計候補をCodex等へ渡し、対象業務アプリケーション実装につなげる成果物として明確化した。
- `ImplementationInstructionGeneratorTest`、`BlueprintGenerationRegressionTest`、`BlueprintGenerationServiceTest`、`BlueprintControllerTest` を追加・更新した。
