## 背景

APIM for Spring のローカルリポジトリ精査により、`ChatExec2_CleanupMergedBranches_APIM.result` が未追跡ファイルとしてリポジトリルートに残っていることを確認した。

既存 `.gitignore` では、`ChatExec.result`、`CodexExec.result`、`.chatexec2/`、`ChatExec-*.out`、`ChatExec-*.err`、`CodexExec-*.out`、`CodexExec-*.err` は除外されていたが、ChatExec2方式のJOB_ID付き結果ファイルである `ChatExec2_*.result` は除外対象になっていなかった。

また、Codex投入用Markdownやローカル実行結果がリポジトリルートに残り、Sourcetree等のGUI上でノイズとして見える問題があったため、今後の運用ルールとして分類と配置方針を明確化した。

## 対応結果

1. `.gitignore` にChatExec2結果ファイルのignoreパターンを追加した。
2. `CodexExec_*.result` をignore対象に追加した。
3. `CodexExec_*.md` は正規文書として保存する場合があるため、一律ignoreしない方針を明文化した。
4. ルート直下に置いてよいもの、残さないものを分類した。
5. ChatExec2スクリプトでは、既知のリポジトリパスを固定値として埋め込み、不要なフォルダ選択を要求しない方針を明文化した。
6. 既存ローカル一時ファイルの削除は、別途ローカルcleanupとして扱う方針を明文化した。
