# TSK-035 ChatExec2方式を並行作業対応の外部実行方式として仕様化する

- ID: TSK-035
- 件名: ChatExec2方式を並行作業対応の外部実行方式として仕様化する
- 状態: 解決済み
- 優先度: High
- 主担当: ChatGPT(リポジトリ編集)
- 関連文書: `docs/00_プロジェクト管理/02_改善タスク管理/ChatExec2方式.md`

## 背景

従来のChatExec方式では、`ChatExec.ps1` / `ChatExec.sh` と `ChatExec.result` を固定ファイル名として扱うため、単独作業では有効である一方、複数作業を並行すると結果ファイルの上書き衝突や取り違えが発生し得る。

そのため、並行作業にも対応できる外部実行オフロード方式として、作業単位・工程単位で一意な `JOB_ID` を付与するChatExec2方式を運用仕様として定義する。

## 対応内容

- ChatExec2方式の運用仕様を追加した。
- 「ChatExec方式で」と指示された場合は原則ChatExec2方式を使用する方針を明記した。
- 旧版の固定 `ChatExec.result` 方式を使う条件を明記した。
- GitHub Issue/PRコメント方式を標準案として定義した。
- GitHubコメントに含める情報・含めてはならない情報を整理した。
- `.result` を通常作業ブランチへ commit & push する方式を非推奨として明記した。
- クリーンアップ方針を整理した。

## 対象外

- ChatExec2用スクリプトテンプレートの実装
- GitHub Issue自動作成スクリプトの実装
- 既存CIの変更
- アプリケーションコード変更

## 完了条件

- ChatExec2方式の標準運用が文書化されている。 → 完了
- 旧版ChatExec方式を使用する例外条件が文書化されている。 → 完了
- GitHub Issue/PRコメント方式の安全要件が文書化されている。 → 完了
- 通常作業ブランチへの `.result` commit & push が非推奨として明記されている。 → 完了
