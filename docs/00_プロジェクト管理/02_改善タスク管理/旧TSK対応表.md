今後の正規タスクIDは `TSK-###` とし、`APIM-###` の新規タスク採番は行わない。

## 3. 運用ルール

- 本表は過去互換のために維持する。
- 新規タスクでは `APIM-###` を採番しない。
- 新規タスクでは `TSK-###` を正規IDとして採番する。
- 既存文書でAPIM呼称が残っている場合は、必要に応じて本表で対応関係を確認する。

## 4. 備考
