# TSK-008 Windows環境で spring-boot:run 起動失敗を調査する

- ID: TSK-008
- 件名: Windows環境で spring-boot:run 起動失敗を調査する
- 状態: 未解決
- 優先度: Medium
- 主担当候補: Codex

## 背景

APIM-007のWindows手動確認で、Maven Wrapperによるtest、compile、package、jar起動は成功した。

一方で、spring-boot:run は main class を検出できずに失敗した。

## 確認済み事項

- `mvnw.cmd test`: PASS
- `mvnw.cmd clean compile`: PASS
- `target/classes/com/example/apim/ApimApplication.class`: 存在確認済み
- `mvnw.cmd package`: PASS
- jar起動: PASS
- `http://localhost:8080/`: 表示確認済み

## 調査対象

- Spring Boot Maven Plugin の run 実行時クラスパス
- Windows PowerShell / Maven Wrapper 経由の引数受け渡し
- OneDrive配下パスや日本語パスの影響
- mainClass 明示設定の要否

## 完了条件

- Windows環境で spring-boot:run が成功する、または
- spring-boot:run を非推奨として jar起動方式を正式手順とする判断を文書化する。

## 備考

APIM-007のリリース前確認は、jar起動方式で主要画面・生成フローを確認済みのため、MVP確認のブロッカーではない。
