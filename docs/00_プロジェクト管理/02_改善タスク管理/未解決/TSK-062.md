# TSK-062 旧横断運用規程ファイル群を中枢参照構成へ整理する

状態: 未解決
優先度: High
主担当候補: ChatGPT(リポジトリ編集)
提案名: APIM-LEGACY-OPS-RULES-CLEANUP-02
起票日: 2026-05-10

## 背景

TSK-060により、`api-mcp-blueprint-for-spring` には `chatgpt-ops-rules` への中枢参照が導入された。

一方で、`docs/00_プロジェクト管理/05_横断運用規程/` 配下には、過去にAPIM側へ複製・蓄積された旧横断運用規程ファイル群がまだ残っている。

Spring-Tool-Development-Templateでは、旧横断運用規程の詳細本文を現行ツリーから薄型化し、必要な履歴参照を `docs/90_アーカイブ/旧横断運用規程/README.md` に整理済みである。

APIM側も同様に、共通運用ルール本文を個別リポジトリ側へ重複保持しない構成へ整理する必要がある。

## 目的

`api-mcp-blueprint-for-spring` の旧横断運用規程ファイル群を棚卸しし、`chatgpt-ops-rules` を正本とする中枢参照構成へ整理する。

## 想定作業

1. `docs/00_プロジェクト管理/05_横断運用規程/` 配下の既存mdを棚卸しする。
2. 共通運用ルール本文に該当する旧詳細規程をAPIM側から削除または薄型参照化する。
3. APIM固有の業務仕様、実装仕様、環境依存手順、Render公開準備、設計生成系前提に該当するものはAPIM側へ残す。
4. 履歴参照が必要な旧規程について、`docs/90_アーカイブ/旧横断運用規程/README.md` に整理する。
5. `00_運用ルール索引と実行ゲート.md` と `chatgpt-ops-rules中枢参照方針.md` の整合を確認する。
6. 改善タスク課題一覧と本個票を解決済みへ同期する。
7. merge後cleanup、local main同期、remote tracking branch pruneまで確認する。

## 対象外

- `chatgpt-ops-rules` 側の追加改定。
- TSK-061の作業内容、PR、ブランチ、個票。
- APIMアプリケーション実装変更。
- Render公開操作。
- 外部サービス設定変更。
- 費用発生を伴う操作。
- 既に解決済みのTSK-059 / TSK-060の再作業。
