# TSK-075 インラインJavaScript外出し

状態: 未解決

## 分類

- 登録分類: immediate / next
- 優先度: Medium
- MVP整合性: MVP内
- 発生元: evaluation-recheck-20260526

## 目的

HTMLテンプレートの保守性を改善し、再発修正やUI変更時の影響範囲を読みやすくする。

## 想定変更対象

- HTMLテンプレート
- static JSファイル

## 実装概要

- 既存のインラインJavaScript配置を調査する。
- 影響範囲が小さいものから外部JS化する。
- 画面固有ロジックと共通ロジックを分ける。

## 完了条件

- 対象範囲のインラインJavaScriptが整理されている。
- チェック復元、プレビュー復帰、サンプル入力、コピー導線など既存挙動が維持されている。
- 影響が大きい場合は分割TSK化されている。
