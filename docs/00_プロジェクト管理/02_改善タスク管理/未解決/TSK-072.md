# TSK-072 viewport meta追加とスマホ幅確認

状態: 未解決

## 分類

- 登録分類: immediate / investigation
- 優先度: High
- MVP整合性: MVP内
- 発生元: evaluation-recheck-20260526

## 目的

スマートフォン幅やGitHub Pages/提出時閲覧での表示崩れを防ぐ。

TSK-087「スマホ幅・主要画面表示確認」の確認範囲を本TSKへ統合し、以後のスマホ幅・主要画面表示確認は本TSKで追跡する。

## 想定変更対象

- HTMLテンプレート共通head部
- 各画面テンプレート

## 実装概要

- viewport metaが不足している画面を確認する。
- 不足している場合は追加する。
- 主要画面をスマホ幅で確認する。
- 確認結果を記録する。

## 確認観点

- viewport metaの有無確認
- viewport metaが不足している場合の追加
- トップ画面のスマホ幅確認
- 結果画面のスマホ幅確認
- Markdown設計書プレビューのスマホ幅確認
- AI実装指示書プレビューのスマホ幅確認
- ヘルプ画面のスマホ幅確認
- 確認結果の記録
- 表示崩れがある場合の個別TSK化

## 完了条件

- 主要画面にviewport metaが適切に設定されている。
- トップ、結果、Markdown設計書プレビュー、AI実装指示書プレビュー、ヘルプ画面のスマホ幅確認結果が記録されている。
- 表示崩れがある場合は追加TSK化する。

## 関連
