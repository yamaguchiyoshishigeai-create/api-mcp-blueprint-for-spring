## 背景

Renderで `main` の `22d25ea96b324d9b107bfea845852e8a8bd0f6de` をデプロイしたところ、Docker build中に失敗した。

失敗箇所は `Dockerfile` の build stage における以下の工程である。

```text
RUN ./mvnw -B -DskipTests dependency:go-offline
```

Renderログ上では、Maven Wrapper が Maven をダウンロードした後、zip展開に必要な `unzip` が見つからず停止している。

```text
./mvnw: 42: unzip: not found
error: failed to solve: process "/bin/sh -c ./mvnw -B -DskipTests dependency:go-offline" did not complete successfully: exit code: 127
```

現行 `Dockerfile` は `eclipse-temurin:17-jdk` をbuild stageとして使用しているが、`./mvnw` 実行前に `unzip` をインストールしていない。

## 目的

Render上のDocker buildで Maven Wrapper が正常にMavenを展開できるよう、build stageに `unzip` を追加する。

これにより、Render公開作業がDocker build段階で失敗しない状態にする。

## 修正対象

主対象:

- `Dockerfile`

想定される確認対象:

## 修正方針

1. `Dockerfile` の build stage で、`./mvnw` 実行前に `unzip` をインストールする。
2. 例として、Debian/Ubuntu系の `eclipse-temurin:17-jdk` で以下を追加する。

```dockerfile
RUN apt-get update \
    && apt-get install -y --no-install-recommends unzip \
    && rm -rf /var/lib/apt/lists/*
```

3. 追加位置は、`FROM eclipse-temurin:17-jdk AS build` / `WORKDIR /workspace` の後、少なくとも `RUN ./mvnw -B -DskipTests dependency:go-offline` より前とする。
4. runtime stageには不要なため、`unzip` はbuild stageにのみ追加する。
5. Docker buildが成功することを確認する。
6. CIがsuccessであることを確認する。
