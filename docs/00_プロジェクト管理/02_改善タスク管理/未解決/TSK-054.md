# TSK-054 Spring-Tool-Development-TemplateへTSK-047/048/050系運用ルールを部分横展開する

## 状態

未解決

## 優先度

Medium

## 主担当候補

ChatGPT(リポジトリ編集)

## 背景

TSK-053で、APIM for Springに追加されたTSK-047 / TSK-048 / TSK-050系運用ルールについて、関連リポジトリへの横展開要否を判断した。

`Spring-Tool-Development-Template` はPR #31で運用ルールHubとCodex投入ゲートを横展開済みである。一方、TSK-047 / TSK-048 / TSK-050で追加した以下の方針は完全一致では確認できなかった。

1. ローカル一時ファイルとルート直下整理方針。
2. CIポーリング終了条件固定方針。
3. Merge後cleanup・local sync自動統合方針。

Spring系派生ツール開発テンプレートでは、ChatExec2、Codex、CI、branch cleanupを利用する可能性が高いため、APIM固有の例を抽象化したうえで部分横展開する。

## 対応内容

1. `Spring-Tool-Development-Template` の既存横断運用規程を確認する。
2. TSK-047 / TSK-048 / TSK-050相当のうち、テンプレートとして必要な内容を抽出する。
3. APIM固有のファイル名、PR番号、TSK例をテンプレート向け表現へ抽象化する。
4. 必要に応じて運用ルールHubから参照できるようにする。
5. PR作成、CI確認、main反映、merge後cleanupを行う。

## 実施しないこと

- APIM固有文書を無条件コピーすること。
- 実装コード変更。
- CI workflow変更。
- Q-Scoutまたはportfolioへの同時反映。

## 完了条件

- `Spring-Tool-Development-Template` に必要な運用ルールが部分反映されていること。
- テンプレートとして再利用可能な抽象表現になっていること。
- PRのCIがsuccessであること。
- mainへmerge済みであること。
- merge後cleanupとlocal syncが完了していること。
