# TSK-019 チェックボックス群に全選択・全解除を追加する

- ID: TSK-019
- 件名: チェックボックス群に全選択・全解除を追加する
- 状態: 未解決
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

構造化入力UIでは、必要操作、AI許可操作、AI禁止操作、読み取り専用操作、書き込み操作、承認必須操作、監査ログ必須操作など、複数のチェックボックス群を扱う。

チェックボックス数が増えると、ユーザーが個別にON/OFFする操作負荷が高くなる。

## 課題

現行UIには、各チェックボックス群ごとの全選択・全解除操作がない。

そのため、標準案を一括調整したい場合や、候補を一度リセットしたい場合に操作負荷が高い。

## 対応方針

各チェックボックス群に「全選択」「全解除」を追加する。

対象は、少なくとも以下とする。

- 利用者種別
- 必要な操作
- AIアシスタントに許可したい操作
- AIに禁止する操作
- 読み取り専用操作
- 書き込み許可操作
- 承認必須操作
- 監査ログが必要な操作

## 完了条件

- 各チェックボックス群で全選択・全解除ができる。
- 既存のサンプル入力と送信前集約処理が維持される。
- CIが成功する。
