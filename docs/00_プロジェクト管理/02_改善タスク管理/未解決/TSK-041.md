# TSK-041 Render公開準備を整備する

- ID: TSK-041
- 件名: Render公開準備を整備する
- 状態: 未解決
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集) / Codex
- 関連タスク:
  - TSK-042 初回訪問者向け体験ルートを実装する

## 背景

APIM for Spring はローカルMVPとして、API設計書、MCP設計候補、API/MCP対応表、AI実装指示書を生成できる状態になっている。

一方で、外部訪問者が実際に触れる公開環境はまだ整備されていない。Renderへ登録し、公開URLからWeb MVPへアクセスできる状態にする必要がある。

ただし、公開前に初回訪問者が価値を理解しやすい体験ルートを整える方が効果的であるため、TSK-042を先行実施し、その後TSK-041でRender公開準備を行う。

## 目的

APIM for Spring をRenderへ登録・公開できるよう、起動設定、環境変数、README、疎通確認手順を整備する。

## 実施すること

- Render向けの起動方式を整理する。
- Java 17 / Maven Wrapper を前提としたbuild/start手順を整理する。
- Renderの `PORT` 環境変数にSpring Bootが追従できるか確認し、必要に応じて設定を追加する。
- READMEへRenderデプロイ手順を追加する。
- 公開後の疎通確認観点を整理する。
- 必要に応じて簡易health endpointまたは既存 `/` アクセス確認手順を明確化する。

## 実施しないこと

- DB永続化。
- 外部LLM API連携。
- 認証・認可の本格実装。
- 完全動作するMCPサーバー実装。
- 本番運用レベルの監視・アラート設計。

## 完了条件

- RenderでAPIM for Springを公開するためのbuild/start設定が明確になっている。
- READMEにRender公開手順が記載されている。
- 公開URLで `/` にアクセスし、初回体験ルートを試せる前提が整っている。
- TSK-042で実装する初回体験導線との整合が取れている。
