# TSK-060 chatgpt-ops-rules 中枢参照導入

状態: 未解決
優先度: High
主担当候補: ChatGPT(リポジトリ編集)
提案名: APIM-CENTRAL-REF-TSK060-01
起票日: 2026-05-10

## 背景

`chatgpt-ops-rules` が共通運用ルールの正本として整備され、TSK-009からTSK-012により、通常PR自動merge方針、ChatExec2 Windows bat標準、個票先行main反映ゲート、FullFlow bat一括実行方針が追加された。

一方、`api-mcp-blueprint-for-spring` 側には、過去の横断運用規程やリポジトリ固有運用が残っており、共通運用ルール正本との参照関係を明確化する必要がある。

## 目的

`api-mcp-blueprint-for-spring` に `chatgpt-ops-rules` への中枢参照を導入し、共通運用ルールとAPIM固有ルールの分離を明確化する。

## 想定作業

本個票は、TSK-011で定義された「個票先行main反映ゲート」に従い、本体作業前に先行してmainへ反映する。

本体作業では、以下を検討・反映する。

1. `PROJECT_START_PROMPT.md` に `chatgpt-ops-rules` 参照を追加する。
2. `README.md` / `docs/README.md` に中枢参照導線を追加する。
3. `docs/00_プロジェクト管理/05_横断運用規程/00_運用ルール索引と実行ゲート.md` を中枢参照スタブへ薄型化する。
4. APIM固有の業務仕様、設計生成系前提、実装仕様はAPIM側に残す。
5. 旧横断運用規程の履歴参照が必要な場合は、`docs/90_アーカイブ/旧横断運用規程/README.md` 等へ整理する。
6. APIM側に共通運用ルール本文を重複コピーしない。
7. 反映後に発生・残存課題の未個票化がないか確認する。
