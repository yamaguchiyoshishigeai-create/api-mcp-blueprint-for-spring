# TSK-034 MCP Generatorを複数ドメイン対応へ拡張する

- ID: TSK-034
- 件名: MCP Generatorを複数ドメイン対応へ拡張する
- 状態: 未解決
- 優先度: High
- 主担当候補: Codex
- 関連文書: `docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md`

## 背景

複数ドメイン入力を扱う場合、MCP tools / resources / prompts は主ドメイン、関連ドメイン、横断操作の境界を意識して生成する必要がある。

特にAI操作では、参照・書き込み・承認必須・監査ログ対象の範囲がドメインごとに異なる可能性があるため、MCP Generator側でも境界を明示する必要がある。

## 実施内容

- MCP toolsを主ドメインtool、関連ドメインtool、横断toolに分けて生成する。
- MCP resourcesを主ドメインresource、関連resource、横断resourceに分けて生成する。
- MCP promptsに複数ドメインを扱う際の禁止事項・人間確認条件を反映する。
- API / MCP tool 対応表にドメイン境界を反映する。
- 書き込み操作、削除操作、外部送信、権限変更について承認・監査ログ観点を維持する。

## 対象外

- 完全動作するMCPサーバー実装
- 外部LLM API連携
- 認証認可コードの本格実装

## 完了条件

- 複数ドメイン入力時に、MCP候補が主ドメイン・関連ドメイン・横断操作の境界を意識して生成される。
- セキュリティ・承認・監査ログ観点が維持されている。
- 単一ドメイン入力の既存生成結果互換が維持されている。
- テストが更新され、CIがsuccessである。
