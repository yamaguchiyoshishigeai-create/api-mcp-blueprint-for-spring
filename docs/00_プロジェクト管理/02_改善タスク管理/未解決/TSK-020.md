# TSK-020 システム種別プリセットから標準ドメイン・標準操作を自動投入する

- ID: TSK-020
- 件名: システム種別プリセットから標準ドメイン・標準操作を自動投入する
- 状態: 未解決
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集)

## 背景

構造化入力UIでは、ユーザーが対象ドメイン、利用者、操作種別、承認必須操作、監査ログ対象などを選択する。

一方、代表的な対象システムを選んだ場合、標準的に必要となるドメインや操作はある程度決まっている。

## 課題

ユーザーが白紙状態から全項目を選ぶ方式では、チェック項目が増えるほど操作負荷が高くなる。

また、初心者ユーザーにとっては、どのドメインや操作を選ぶべきか判断しにくい。

## 対応方針

対象システム種別プリセットを追加し、選択時に標準ドメイン、主ドメイン、利用者種別、必要操作、AI許可操作、AI禁止操作、承認必須操作、監査ログ対象を自動投入する。

初期候補例:

- 社内申請ポータル
- EC / 販売管理
- 保守サポート管理
- ナレッジ活用基盤

ユーザーは自動投入された標準案を起点に、不要な項目を外し、必要な項目を追加する。

## 完了条件

- 対象システム種別の選択により、標準ドメインと標準操作が自動投入される。
- ユーザーが自動投入後に各チェック項目を調整できる。
- 既存の送信前集約処理が維持される。
- CIが成功する。
