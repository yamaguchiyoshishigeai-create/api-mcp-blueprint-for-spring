# TSK-047 ルート直下ノイズ整理とignore方針を整備する

## 状態

未解決

## 優先度

High

## 主担当候補

ChatGPT(リポジトリ編集)

## 背景

APIM for Spring のローカルリポジトリ精査により、`ChatExec2_CleanupMergedBranches_APIM.result` が未追跡ファイルとしてリポジトリルートに残っていることを確認した。

既存 `.gitignore` では、`ChatExec.result`、`CodexExec.result`、`.chatexec2/`、`ChatExec-*.out`、`ChatExec-*.err`、`CodexExec-*.out`、`CodexExec-*.err` は除外されているが、ChatExec2方式のJOB_ID付き結果ファイルである `ChatExec2_*.result` は除外対象になっていなかった。

また、Codex投入用Markdownやローカル実行結果がリポジトリルートに残り、Sourcetree等のGUI上でノイズとして見える問題があるため、今後の運用ルールとして分類と配置方針を明確化する必要がある。

## 対応内容

1. `.gitignore` にChatExec2結果ファイルのignoreパターンを追加する。
2. `CodexExec_*.result` をignore対象に追加する。
3. `CodexExec_*.md` は正規文書として保存する場合があるため、一律ignoreしない方針を明文化する。
4. ルート直下に置いてよいもの、残さないものを分類する。
5. ChatExec2スクリプトでは、既知のリポジトリパスを固定値として埋め込み、不要なフォルダ選択を要求しない方針を明文化する。
6. 既存ローカル一時ファイルの削除は、別途ローカルcleanupとして扱う。

## 実施しないこと

- 実装コード変更。
- テストコード変更。
- 既存の正規文書削除。
- `CodexExec_*.md` の一律ignore化。
- ローカルファイルの強制削除。
- 他リポジトリへの横展開。

## 完了条件

- `.gitignore` に `ChatExec2_*.result` 等のignoreパターンが追加されていること。
- `CodexExec_*.result` がignore対象に追加されていること。
- ローカル一時ファイルとルート直下整理方針が横断運用規程として追加されていること。
- TSK-047が改善タスク課題一覧へ登録されていること。
- PRのCIがsuccessであること。
- mainへmerge済みであること。
