# TSK-027 カテゴリ別ドメイン候補をnode表示へ整理する

- ID: TSK-027
- 件名: カテゴリ別ドメイン候補をnode表示へ整理する
- 状態: 未解決
- 優先度: High
- 主担当候補: ChatGPT(リポジトリ編集) / Codex
- 関連設計書: `docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md`

## 背景

TSK-021により、カテゴリ別ドメイン候補はUI上に追加された。

しかし現行UIでは、カテゴリ名とチェックボックス群の見た目上のまとまりが弱く、各ドメインがどのカテゴリに属しているかを直感的に把握しにくい。

## 課題

ドメイン候補が増えるほど、単純なチェックボックス列では視認性が下がる。

ユーザーが対象ドメインを選ぶ際に、カテゴリ単位の意味や関連性を把握しやすいUIが必要である。

## 対応方針

カテゴリ別ドメイン候補を、カテゴリごとのnodeまたはカード表示へ整理する。

各カテゴリを視覚的に分離し、カテゴリ名、説明、候補チェックボックス群がまとまって見える構造にする。

## 実施対象

- カテゴリごとのfieldsetまたはカード表示化
- カテゴリ名の視認性向上
- カテゴリ説明の追加検討
- 既存の `data-target="domainCatalog"` 構造の維持
- 全選択・全解除および対象ドメイン欄への自動反映処理の維持

## 実施しないこと

- 対象システム種別プリセットの拡充
- `BlueprintInput` のフィールド追加
- Generatorの複数ドメイン対応
- Markdown出力のドメイン境界対応

## 完了条件

- カテゴリ別ドメイン候補がnodeまたはカード形式で表示される。
- ドメインがどのカテゴリに属しているか見た目で分かる。
- 既存の複数ドメイン選択と対象ドメイン欄への自動反映が維持される。
- CIが成功する。
