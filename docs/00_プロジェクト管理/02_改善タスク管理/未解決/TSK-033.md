# TSK-033 API Generatorを複数ドメイン対応へ拡張する

- ID: TSK-033
- 件名: API Generatorを複数ドメイン対応へ拡張する
- 状態: 未解決
- 優先度: High
- 主担当候補: Codex
- 関連文書: `docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md`

## 背景

複数ドメイン入力を `targetDomain` の単一文字列として扱うだけでは、主ドメインAPI、関連ドメイン参照API、横断操作の境界が曖昧になる。

正規化済み入力を前提に、API設計生成を複数ドメインに対応させる必要がある。

## 実施内容

- API Generatorで主ドメインAPIと関連ドメイン参照APIを分ける。
- Controller候補が過大にならないよう、ドメイン別Controller候補を生成する。
- DTO候補をドメイン別に生成する。
- 既存単一ドメイン入力の生成結果互換を維持する。
- 回帰テストを追加・更新する。

## 対象外

- MCP Generatorの複数ドメイン対応
- 実際のController実装生成
- DB Entity / Repository / Service完全実装

## 完了条件

- 複数ドメイン入力時に、API候補が主ドメイン・関連ドメインの境界を意識して生成される。
- 単一ドメイン入力の既存生成結果互換が維持されている。
- テストが更新され、CIがsuccessである。
