# TSK-055 Q-Scout-for-SpringへTSK-047/048/050系運用ルールを部分横展開する

## 状態

未解決

## 優先度

Medium

## 主担当候補

ChatGPT(リポジトリ編集)

## 背景

TSK-053で、APIM for Springに追加されたTSK-047 / TSK-048 / TSK-050系運用ルールについて、関連リポジトリへの横展開要否を判断した。

`Q-Scout-for-Spring` はPR #90で運用ルールHubとCodex投入ゲートを横展開済みである。一方、TSK-047 / TSK-048 / TSK-050で追加した以下の方針は完全一致では確認できなかった。

1. ローカル一時ファイルとルート直下整理方針。
2. CIポーリング終了条件固定方針。
3. Merge後cleanup・local sync自動統合方針。

Q-ScoutはSpring系プロダクトであり、APIMと同様にChatExec2、Codex、CI、branch cleanupを利用するため、既存運用規程との整合を取りつつ部分横展開する。

## 対応内容

1. `Q-Scout-for-Spring` の既存横断運用規程を確認する。
2. TSK-047 / TSK-048 / TSK-050相当のうち、Q-Scoutで必要な内容を抽出する。
3. APIM固有のファイル名、PR番号、TSK例をQ-Scout向け表現へ調整する。
4. 必要に応じて運用ルールHubから参照できるようにする。
5. PR作成、CI確認、main反映、merge後cleanupを行う。

## 実施しないこと

- APIM固有文書を無条件コピーすること。
- 実装コード変更。
- CI workflow変更。
- Spring-Tool-Development-Templateまたはportfolioへの同時反映。

## 完了条件

- `Q-Scout-for-Spring` に必要な運用ルールが部分反映されていること。
- Q-Scout既存運用規程と矛盾していないこと。
- PRのCIがsuccessであること。
- mainへmerge済みであること。
- merge後cleanupとlocal syncが完了していること。
