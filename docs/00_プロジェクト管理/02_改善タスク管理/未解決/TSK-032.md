# TSK-032 Markdown設計書とAI実装指示書にドメイン境界を表示する

- ID: TSK-032
- 件名: Markdown設計書とAI実装指示書にドメイン境界を表示する
- 状態: 未解決
- 優先度: High
- 主担当候補: Codex
- 関連文書: `docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md`

## 背景

複数システム・複数ドメイン入力を扱う場合、生成されるMarkdown設計書とAI実装指示書に、対象システム種別、主ドメイン、関連ドメインの境界が表示されていないと、後続実装時に責務境界が曖昧になる。

## 実施内容

- Markdown設計書に対象システム種別、主ドメイン、関連ドメインの入力サマリーを追加する。
- AI実装指示書に主ドメインと関連ドメインの実装境界に関する注意を追加する。
- この段階では、API候補・MCP候補の完全なドメイン別分解までは行わない。

## 対象外

- API Generatorの複数ドメイン対応
- MCP Generatorの複数ドメイン対応
- Controller候補のドメイン別分割
- DTO候補のドメイン別分割

## 完了条件

- Markdown設計書で複数システム・複数ドメインの境界を確認できる。
- AI実装指示書で主ドメイン・関連ドメインの実装境界が確認できる。
- 既存生成結果の後方互換が維持されている。
- CIがsuccessである。
