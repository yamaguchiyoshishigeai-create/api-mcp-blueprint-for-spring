# TSK-031 NormalizedBlueprintInput を導入する

- ID: TSK-031
- 件名: `NormalizedBlueprintInput` を導入する
- 状態: 未解決
- 優先度: High
- 主担当候補: Codex
- 関連文書: `docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md`

## 背景

複数システム・複数ドメイン入力をGeneratorへ直接渡すと、旧入力互換処理や `targetDomain` の分解処理が各Generatorへ散在するリスクがある。

この問題を防ぐため、Generatorへ渡す前に入力を正規化する内部モデルを導入する。

## 実施内容

- `NormalizedBlueprintInput` を追加する。
- 旧入力である `targetDomain` のみのケースを扱えるようにする。
- 新入力である `systemTypes`、`primaryDomain`、`relatedDomains` がある場合はそれを優先する。
- `BlueprintGenerationService` を正規化済み入力経由へ変更する。
- 既存Generatorへの影響を最小化する。

## 対象外

- API Generatorの複数ドメイン対応
- MCP Generatorの複数ドメイン対応
- Markdown設計書の大幅な章構成変更

## 完了条件

- Generator前段で正規化済み入力を生成できる。
- 旧入力互換が維持されている。
- 既存テストが更新され、CIがsuccessである。
