## 背景

APIM-003でMVP要件を定義し、APIM-004で基本設計を定義したため、Web MVPの最小実装に進む。

Spring Boot Webアプリとして、入力フォーム、生成処理、生成結果表示、Markdown設計書プレビュー、AI実装指示書プレビュー、最小テストを実装する。

## 完了条件

- `mvn test` が成功する。
- 入力画面にアクセスできる。
- サンプル入力から生成結果画面を表示できる。
- Markdown設計書とAI実装指示書をプレビューできる。
- MCPサーバー、DB永続化、外部LLM API連携は実装されていない。
