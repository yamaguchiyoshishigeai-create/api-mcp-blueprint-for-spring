- 件名: API Generatorを複数ドメイン対応へ拡張する

- 優先度: High
- 主担当候補: Codex

## 背景

複数ドメイン入力を `targetDomain` の単一文字列として扱うだけでは、主ドメインAPI、関連ドメイン参照API、横断操作の境界が曖昧になる。

TSK-031で正規化レイヤが導入され、TSK-032で生成成果物上のドメイン境界表示が追加されたため、TSK-033ではAPI Generatorの出力を主ドメイン・関連ドメインの境界を意識した候補生成へ拡張する。

## 最小実装境界

TSK-033では、API設計生成において、主ドメインAPI、関連ドメイン参照API、ドメイン別Controller候補、ドメイン別DTO候補が確認できる出力へ拡張する範囲に限定する。

## TSK-033で実施すること

- API Generatorで主ドメインAPIと関連ドメイン参照APIを分ける。
- Controller候補が過大にならないよう、ドメイン別Controller候補を生成する。
- DTO候補をドメイン別に生成する。
- 既存単一ドメイン入力の生成結果互換を維持する。
- 必要最小限のテストを追加・更新する。

## TSK-033で実施しないこと

- MCP Generatorの複数ドメイン対応。
- tool / resource / prompt 候補のドメイン別分割。
- 実際のController実装生成。
- DB Entity / Repository / Service完全実装。
- 永続化設計の本格拡張。
- TSK-034の範囲に含まれる実装。

## 完了条件

- 複数ドメイン入力時に、API候補が主ドメイン・関連ドメインの境界を意識して生成される。
- Controller候補とDTO候補がドメイン境界を意識して生成される。
- 単一ドメイン入力の既存生成結果互換が維持されている。
- MCP Generatorの複数ドメイン対応へ越境していない。
- テストが更新され、CIがsuccessである。
