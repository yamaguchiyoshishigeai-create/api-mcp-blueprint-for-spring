# TSK-034 MCP Generatorを複数ドメイン対応へ拡張する

- ID: TSK-034
- 件名: MCP Generatorを複数ドメイン対応へ拡張する
- 状態: 解決中
- 優先度: High
- 主担当候補: Codex
- 関連文書:
  - docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md
  - docs/00_プロジェクト管理/03_実装支援AI指示/TSK-034-最小実装指示.md

## 背景

TSK-031で正規化レイヤが導入され、TSK-032で生成成果物上のドメイン境界表示が追加され、TSK-033でAPI Generatorが主ドメインAPIと関連ドメイン参照APIの境界に対応した。

TSK-034では、MCP Generatorのtools / resources / prompts候補を、主ドメイン・関連ドメイン・横断操作の境界を意識した出力へ拡張する。

## 最小実装境界

TSK-034では、MCP設計生成において、主ドメインtools、関連ドメインresources、横断prompts、API/MCP対応表がドメイン境界を意識して確認できる出力へ拡張する範囲に限定する。

## TSK-034で実施すること

- MCP tools候補を主ドメイン操作と関連ドメイン参照操作に分ける。
- MCP resources候補を主ドメインresourceと関連ドメインresourceに分ける。
- MCP prompts候補に、複数ドメイン横断時の利用場面、禁止事項、人間確認条件を反映する。
- API/MCP対応表を、TSK-033で拡張された主ドメインAPI・関連ドメイン参照APIの境界に合わせる。
- AI実行可否、承認要否、監査ログ要否がドメイン境界と矛盾しないようにする。
- 既存単一ドメイン入力の生成結果互換を維持する。
- 必要最小限のテストを追加・更新する。

## TSK-034で実施しないこと

- 完全動作するMCPサーバー実装。
- MCP仕様への完全準拠検証。
- tool実行ランタイム実装。
- LLM接続処理の実装。
- 認証・認可コードの自動実装。
- DB Entity / Repository / Service完全実装。
- OpenAPI / MCP仕様ファイルの完全生成。

## 完了条件

- 複数ドメイン入力時に、MCP tools / resources / prompts候補が主ドメイン・関連ドメイン・横断境界を意識して生成される。
- API/MCP対応表がTSK-033のAPI境界と整合する。
- AI実行可否、承認要否、監査ログ要否が安全側に整理されている。
- 単一ドメイン入力の既存生成結果互換が維持されている。
- 完全動作MCPサーバー実装へ越境していない。
- テストが更新され、CIがsuccessである。
