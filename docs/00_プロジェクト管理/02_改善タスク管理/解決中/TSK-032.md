# TSK-032 Markdown設計書とAI実装指示書にドメイン境界を表示する

- ID: TSK-032
- 件名: Markdown設計書とAI実装指示書にドメイン境界を表示する
- 状態: 解決中
- 優先度: High
- 主担当候補: Codex
- 関連文書:
  - docs/40_詳細設計/複数ドメイン-複合システム入力モデル設計.md

## 背景

複数システム・複数ドメイン入力を扱う場合、生成されるMarkdown設計書とAI実装指示書に、対象システム種別、主ドメイン、関連ドメインの境界が表示されていないと、後続実装時に責務境界が曖昧になる。

TSK-031で `NormalizedBlueprintInput` と正規化レイヤが導入されたため、TSK-032ではその正規化済み情報を生成成果物上に表示できる状態へ進める。

## 最小実装境界

TSK-032では、Markdown設計書とAI実装指示書に、対象システム種別、主ドメイン、関連ドメイン、正規化後ドメイン一覧が確認できる入力サマリーを追加する範囲に限定する。

## TSK-032で実施すること

- Markdown設計書に対象システム種別、主ドメイン、関連ドメイン、正規化後ドメイン一覧の入力サマリーを追加する。
- AI実装指示書に主ドメインと関連ドメインの実装境界に関する注意を追加する。
- TSK-031で導入された正規化済み入力を利用できる範囲では利用する。
- 既存の単一ドメイン入力や旧入力 `targetDomain` の生成結果に対する後方互換を維持する。
- 必要最小限のテストを追加・更新する。

## TSK-032で実施しないこと

- API Generatorの複数ドメイン対応。
- MCP Generatorの複数ドメイン対応。
- Controller候補のドメイン別分割。
- DTO候補のドメイン別分割。
- tool / resource / prompt 候補のドメイン別分割。
- ドメインごとの完全な生成成果物分解。

## 完了条件

- Markdown設計書で複数システム・複数ドメインの境界を確認できる。
- AI実装指示書で主ドメイン・関連ドメインの実装境界が確認できる。
- 既存生成結果の後方互換が維持されている。
- TSK-033からTSK-034の範囲へ越境していない。
- テストが更新され、CIがsuccessである。
