# TSK-045 最小実装指示

## 1. 作業名

TSK-045 プレビュー画面にダウンロード導線と入力状態復元導線を追加する

## 2. 目的

APIM for Springのプレビュー画面に、生成成果物のダウンロード導線と、入力済み設定を保持したまま入力画面へ戻る導線を追加する。

現状では、プレビュー表示後に成果物をダウンロードする導線がなく、また手作業で設定した入力状態へ戻れないため、生成結果確認後の再編集・再生成体験が弱い。

## 3. 対象ブランチ候補

```text
feature/tsk-045-preview-download-return-state
```

## 4. 参照正本

- `docs/00_プロジェクト管理/02_改善タスク管理/未解決/TSK-045.md`
- `src/main/java/com/example/apim/controller/BlueprintController.java`
- `src/main/resources/templates/index.html`
- `src/main/resources/templates/result.html`
- `src/test/java/com/example/apim/controller/BlueprintControllerTest.java`

既存構成を確認し、実装対象ファイルは必要最小限に調整する。

## 5. 実施すること

- プレビュー画面にMarkdown成果物のダウンロードリンクを追加する。
- プレビュー表示後に、入力済み状態を保持して入力画面へ戻れる導線を追加する。
- 手作業設定したシステム種別、ドメイン、必要操作、AI許可操作、自由入力、出力言語などを保持する。
- 可能であれば、プレビュー画面から「設定を修正して再生成」へ進める導線を追加する。
- 既存の生成結果画面、Markdownダウンロード導線、自由入力フローを壊さない。
- 必要最小限のControllerテストまたは画面テストを追加・更新する。

## 6. 実施しないこと

- TSK-046の複数サンプルボタン化。
- Render公開作業そのもの。
- 外部LLM API連携。
- DB永続化。
- 認証・認可の本格実装。
- 完全動作するMCPサーバー実装。
- 大規模UI全面刷新。

## 7. テスト観点

- プレビュー画面にダウンロードリンクが表示されること。
- プレビュー後に、入力済み設定を保持した状態で入力画面へ戻れること。
- 手作業設定した入力内容が不用意に消えないこと。
- 既存の生成結果画面、ダウンロード導線、自由入力POSTフローが壊れていないこと。

## 8. テストコマンド

Windows:

```bash
./mvnw.cmd test
```

Linux/macOS/WSL:

```bash
./mvnw test
```
