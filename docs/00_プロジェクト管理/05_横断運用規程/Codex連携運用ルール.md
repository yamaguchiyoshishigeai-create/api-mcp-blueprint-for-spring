# Codex連携運用ルール

## 目的

APIM for Spring リポジトリにおける Codex 作業の安全性、再現性、監査可能性を担保する。

## 基本原則

- docs正本を起点に作業する
- 機能未実装を実装済み扱いしない
- APIMは設計生成系であり、診断・スコアリング系として扱わない

## 実行分類

- 読み取り専用: 調査、要件確認、ドキュメント参照
- 書き込み許可: 承認済みの文書更新、タスク更新、テンプレート整備
- 承認必須: main反映、機密情報操作、外部公開影響がある操作

## Git運用

- `main` への直接push禁止
- `main` への直接merge禁止
- 作業は機能ブランチで実施
- PRで差分と検証結果を明示
