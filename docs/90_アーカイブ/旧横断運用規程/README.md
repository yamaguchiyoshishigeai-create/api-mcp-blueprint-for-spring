# 旧横断運用規程アーカイブ

## 1. 位置づけ

このディレクトリは、`api-mcp-blueprint-for-spring` に過去存在していた旧横断運用規程の履歴参照先を記録するためのアーカイブである。

旧横断運用規程のうち、共通運用ルール本文に該当する詳細規程は、現行ツリーには保持しない。理由は、`chatgpt-ops-rules` が共通運用ルールの正本となった後もAPIM側へ旧詳細規程本文を残すと、以下の問題が発生するためである。

- 新規チャット開始時に、APIM固有ルールと中枢ルールを二重に読ませ、コンテキスト負荷を増やす。
- `chatgpt-ops-rules` 側で更新された共通ルールと、APIM側に残った旧ルールが衝突する。
- どちらが正本か不明瞭になる。
- APIM側の業務仕様・実装仕様と、共通運用ルール本文の境界が曖昧になる。

## 2. 現在の正本

現在の共通運用ルールの正本は、以下のリポジトリで管理する。

- `yamaguchiyoshishigeai-create/chatgpt-ops-rules`

APIM固有の業務仕様、実装仕様、環境依存手順、Render公開準備、設計生成系としての製品前提は、引き続き `api-mcp-blueprint-for-spring` 側で管理する。

## 4. 現行ツリーに残す文書

APIM側の現行ツリーでは、以下を維持する。

| 文書 | 理由 |
|---|---|
| `00_運用ルール索引と実行ゲート.md` | APIM側の作業開始入口として必要 |

| `AIリポジトリ作業証跡管理ルール.md` | APIM側に残る作業証跡管理として維持 |
| `Codex連携運用ルール.md` | APIM側の実装支援AI連携に関する入口として維持 |

## 5. 注意

旧規程本文を復元して現行ツリーへ戻す場合は、`chatgpt-ops-rules` との重複・衝突・正本不明確化が発生しないかを確認する。
